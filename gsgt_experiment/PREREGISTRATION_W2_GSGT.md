# 预注册｜W2-GSGT 确认性实验

**版本**：v1.0（冻结）
**冻结时间**：2026-11-05（Asia/Shanghai）
**性质**：**确认性**（confirmatory）。此前 `run_gsgt.py` 的 seeds 0–29 为**探索性**运行，仅用于形成假设与 debug；**不得作为正式结果引用**。本文件冻结后，用全新独立种子 `1000–1029` 执行 `run_gsgt_confirmatory.py`，只有该次输出作为论文级证据。

**与 W1 的关系**：W1 已按失败条款**放弃 PARI**（`pari_diagnostic_results.json` 裁定：无一致优势、A1 无效）。本预注册是一个**新问题、新 estimand、新架构**，不是给旧方法补数据。

---

## 1. 为什么换方向（事前论证，非事后辩解）

W1 的 E5 已量化：群间温度离散度 s: 0→1.2 时，强制单一全局 T 的校准后悔 **0.0005 → 0.1557**。

> 因此 W1 失败的**根因是目标函数**：PARI 与 pooled 都在拟合「一个全局标量 T」去解释一个已证实异质的世界。任何单标量估计器在此设定下必然接近同一个折中值，互相比不出优势。

**新 estimand**：不求 T，求 `T_1 … T_G` —— G 个群（cart_id / site / 年份 / 导联子集，均为**可观测部署元数据**）各自的温度，并用群邻接图做收缩。

**架构变更**：点估计器（1 维）→ 图正则群结构化估计器（G 维 + Laplacian 先验）。保持 post-hoc、冻结模型、无目标标签，不重训 backbone。

**与已有工作的边界**（必须写进 Related Work）：
| 工作 | 差别 |
|---|---|
| MD-TS (Yu/Bates/Ma/Jordan) | 用 embedding 回归预测 T，需 domain label，未见域靠线性外推；GSGT 用**已知元数据图**，不学映射 |
| ECL (ICML 2026) | 训练期 loss、改模型；GSGT 是 post-hoc 估计 |
| EB shrinkage (clawRxiv) / curvature shrinkage (RS) | shrink 到**全局/源域单一均值**；GSGT shrink 到**图邻居共识** |
| Calibration Transfer Gap | 否定「从 3 个标量恢复条件正确率曲线」；GSGT 不恢复曲线，从 G 个直方图 + 已知图恢复 G 个标量，不触碰该不可识别性 |
| BCTS / BBSE / MLLS | 处理 label shift 先验；GSGT 处理 confidence distortion |

**novelty 精确声明**：首次把「设备/时间/中心邻接图」作为温度收缩先验，用于跨语料 ECG 部署校准，并在 1.15M 队列上做 leave-one-site / cart / year 外验。**不声称**首次无标签校准、首次图正则、首次层次收缩。

## 2. DGP（冻结）

- G = 12 群，3 个家族；真实 `log T_g = 家族均值 + N(0, 0.08)`，家族均值 `log 2.4 ± spread`，**spread = 0.9**
- 群规模长尾：lognormal(4.6, 1.35)，clip 到 [15, 2500]；**多数小群、少数大群**（对应 MIMIC cart_id / CODE site）
- 患者原型 `p_i`：背景 0.12，慢性主类 0.55–0.80，归一化。**患者原型可交换，不注入任何帮助 GSGT 的结构**
- **标签 `y_i ~ Cat(p_i)`**（不是 argmax）—— 使 `p_i` 为真实条件概率
- 观测 logits `z_ij = T_g · (log p_i + ε)`，ε ~ N(0, 0.35)
- 源域已校准（τ_s = 1），提供 20,000 条参考样本得到 `h_ref`
- 图 W：家族内边权 1.0，跨家族 0.02（**来自元数据，非无标签推断**）
- 每格 30 个独立种子；确认性种子 **1000–1029**

### F0 有效性门槛（硬性，先于一切结果）
1. `ORACLE`（真实 T_g）的 ECE 必须 ≤ 所有估计器最优值 + 0.001
2. `ORACLE` 的 NLL 必须 ≤ 所有估计器最优值 + 0.001（NLL 对 T 严格凸，是无分箱噪声的交叉校验）
3. **任一不满足 → 实现无效，全部结果作废，不得报告任何数字**

> F0 是 debug 门槛，不是结果挑选。W2 探索性首轮曾因「标签被固定为主类」导致 ORACLE 反而最差，已据此修正 DGP；该修正**写入本预注册后才做确认性复现**。

## 3. 估计器与 λ（冻结）

`Ψ_g(T) = || h_g(T) − h_ref ||²`，在 T 网格 `exp(linspace(log 0.7, log 5.0, 221))` 上预计算 G×221 表；所有拟合**只在该表上操作，不接触标签**。

| 名称 | 定义 |
|---|---|
| SOURCE | T ≡ 1 |
| GLOBAL | `argmin_T Σ_g n_g Ψ_g(T)`（= W1 的 pooled / 原项目 TS） |
| INDEP | 每群独立 `argmin_T Ψ_g(T)` |
| SHRINK-GLOBAL | EB 式向全局均值收缩，先验方差由 indep 拟合经验方差估计 |
| **GSGT** | `min Σ_g n_g Ψ_g(T_g) + λ Σ_{(g,h)} W_gh (log T_g − log T_h)²`，确定性坐标下降 8 轮 |
| ORACLE | 真实 T_g（上界） |

**λ 由留一群无标签交叉验证（`logo_select_lambda`）在 `λ ∈ {0.05,0.1,0.25,0.5,1,2,5,10,25}` 上事前确定**：留一群时该群无 Ψ 项，只靠图邻居预测，用 Ψ_g 打分。**不用标签、不看主终点**。λ 全曲线作为敏感性报告。

## 4. 终点与阈值（冻结）

### 主终点 H1
`ΔECE = ECE(GSGT) − ECE(GLOBAL)`，加权群规模，ECE = top-label 10-bin equal-width。

- **通过**：`mean ΔECE ≤ −0.020`（跨 30 种子），**且** paired 30 种子中 ≥ 27/30 为负，**且** seed1000 的 patient-block bootstrap B=2000 的 95% CI 上界 < 0
- **不通过**：按失败条款降级，不换指标、不换子群、不换分箱数

### 归因拆解（次要，必须报告，禁止合并宣称）
分别报告 `GLOBAL→INDEP`、`INDEP→SHRINK-GLOBAL`、`SHRINK-GLOBAL→GSGT` 三段 ΔECE。**图收缩的贡献单独列，不得把总增益全部归给图正则。**

### 次要终点
| ID | 内容 |
|---|---|
| H2 | λ 选择分布与 LOGO 曲线 |
| S2 | **长尾压力测试**（事前注册）：`n_min=8, size_skew=1.6`，检验「小群越多，GSGT 相对 INDEP 优势越大」这一机制预测。同时如实报告主设定下该增益很小 |
| 辅助 | NLL、Brier、RMSE(log T̂)、小群子集 ECE |

### 分层（事前声明）
`spread ∈ {0.3,0.6,0.9,1.3}` × `size_skew ∈ {0.6,1.0,1.5}` 全网格；阵发性标签层（`episodic_frac=0.3`）单独报告，即使不利。

## 5. 证伪检验（冻结，全部执行）

| ID | 操作 | 预期 |
|---|---|---|
| F-A | `spread=0`（群同质） | GSGT 与 SHRINK-GLOBAL 差异 ≈ 0（\|Δ\| < 0.005） |
| F-B | 置换图 W 的节点 | GSGT 退化（ECE 高于完好图） |
| F-C | 所有群大且均衡 | GSGT ≈ INDEP（无收缩必要，\|Δ\| < 0.005） |
| F-D | 30% 记录标签阵发翻转 | 报告 GSGT 与 GLOBAL；不设通过阈值 |
| F0 | oracle 最优性 | 见第 2 节，硬性 |

**任一 F-A/B/C 不符合预期 → 机制解释不成立，不得声称图结构提供了信息。**

## 6. 统计口径

- patient-block paired bootstrap，B = 2000（合成中每记录一个患者）
- 跨 30 独立种子给 mean ± sd 与 paired 差值 t 统计量
- 同时报 ECE / NLL / Brier；**ECE 的微小 oracle 反转用 NLL 佐证**，不隐藏
- I² 高时禁用固定效应区间（继承原项目教训）

## 7. 失败条款总表

| 触发 | 处置 |
|---|---|
| F0 失败 | 全部作废，修实现后重新冻结注册 |
| H1 未达 −0.020 或 CI 跨零 | GSGT 降级为探索性；回到 BCC + 1.15M 系统验证 + E5 问题结论 |
| 归因显示图收缩贡献 < 0.002 | **novelty 收窄为「群结构化估计」，图收缩仅作为稳健化组件如实描述**，不得包装成主贡献 |
| F-A/B/C 任一不符 | 删除「图结构携带信息」的因果解释 |
| 真实数据（T1）未复现 | 如实发表负面结果，不撤稿、不换指标、不选择性报告 |

> **重要**：探索性轮已显示「图收缩边际增益很小」。本预注册**事前接受**这一可能，并预先写好第 7 条的收窄条款。这不是事后找补。
