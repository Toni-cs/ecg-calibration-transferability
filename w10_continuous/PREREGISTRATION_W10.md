## 0. 端点重定义（本轮第一件事，必须先冻结）

W3 引入的二值 `harm = 1{ECE_k > ECE_GLOBAL + 0.002}` 是为**二值门控**设计的；W9 证明它不适合**连续收缩估计器**（配对 ΔECE 全负、连续量更好，但二值率反而升）。W10 起：

**主终点（连续部署损失）**
```
L_k = mean_seed max(0, ΔECE_k + 0.002)
```
**共同主终点（尾部）**
```
CVaR_0.1%_k = mean of the 20 largest ΔECE_k  (N=20,000)
```
**共同主终点（平均）**
```
A_k = mean_seed ΔECE_k
```
`harm` 降为**次要描述性指标**，仍报告、仍按 0.002 容差，但不作任何判定。

**同时报旧尾部与新尾部**：`CVaR` 用每个方法**自身的**最差 0.1%（禁止只报 CERT 的旧尾部，W9 的教训）。

## 1. 三个候选（全部零超参、零阈值、无需探索集）

记号：`Ti_g = log T̂_g^indep`（无标签 Ψ 拟合），`n_g` 群规模，`T_g^pool` pooled 单温度，`τ̂² = max(Var(Ti) − mean(1/n_g), 0)`，`σ²_g = 1/n_g`，`λ̄ = τ̂²/(τ̂² + mean σ²_g)`。

**基线（W9，供比较）**
- `CERT-GATE`：命题 1 门 + 同方差全局收缩 `λ̄`
- `HB-GST`: 异方差 BLUP `λ_g = τ̂²/(τ̂² + σ²_g)`

**患者级设计效应**（事前写死，由 **GLOBAL 置信度**估计，不依赖任何候选，避免循环）
```
ICC = Var_between_conf / (Var_between_conf + Var_within_patient_conf)
deff = 1 + (m̄ − 1)·ICC,   m̄ = n_rec/n_patient
```
`ICC` 在 [0, 0.95] 截断；`deff ≥ 1`。

### M1｜DEFF-BLUP（患者重复测量修正）
```
σ²_M1,g = deff / n_g
τ̂²_M1   = max(Var(Ti) − mean(σ²_M1,g), 0)
Gate 1:  τ̂²_M1 ≤ mean(σ²_M1,g) ⇒ λ_g = 0 ∀g
否则:    λ_g = τ̂²_M1 / (τ̂²_M1 + σ²_M1,g)
T̂_g = exp(λ_g·Ti_g + (1−λ_g)·log T_g^pool)
```
依据：W7/W9 把 `1/n_g` 当噪声方差，但每患者 ≈2.9 条记录 ⇒ 有效样本量减半；`deff` 是患者级聚类的标准修正。

### M2｜REL-BLEND（可靠性连续混合，逐场景选择，无阈值）
```
λ_LB    = clip(λ̄ − 1.96·SE_jack(λ̄), 0, 1)     # W9 已有的 jackknife 下界
rel     = clip(λ_LB / λ̄, 0, 1)                  # 0=估计不可靠, 1=完全可靠
T̂_g^M2 = exp( rel·log T̂_g^HB + (1−rel)·log T̂_g^CERT )
```
**零阈值**：不做「rel≥c 就选 HB」的硬选择（W8 已证硬门走不通），改为连续混合。估计越不可靠越靠回 CERT 的保守收缩。`λ̄=0` 时 `rel=0`，两者均退化为 GLOBAL。

### M3｜STRAT-CERT（分层证书，直接修 W6-H4 / W9-H4）
分层维度**事前固定为 site**（3 层 × 12 群 = 36，与 DGP 的 site/cart/year 层级一致）。
```
对每个 site 层 h（训练折内可用群 ≥4，否则回退全局 τ̂²）：
    τ̂²_h = max(Var(Ti_h) − mean_h(1/n_g), 0)
    λ_g  = τ̂²_h/(τ̂²_h + 1/n_g)   若 τ̂²_h > mean_h(1/n_g)，否则 0
```
`T^pool` 在同一训练折上拟合。留出折的群**不参与任何拟合**。

> 边界声明：不声称首次 BLUP / 首次经验 Bayes / 首次分层收缩 / 首次 jackknife。边界 = 首次在「ECG 无标签 post-hoc 温度校准 + 患者内重复测量 + 层级长尾部署群」这一具体设置下，把命题 1/2 与部署可靠性统一到连续端点，并系统验证尾部风险是否被搬运。

## 2. 选择规则（事前冻结，无任何结果信息）

**三不劣判据**（相对 `HB-GST`，逐条配对，单位=种子）：
```
合格(k) ⟺  L_k ≤ L_HB  且  CVaR_k ≤ CVaR_HB  且  A_k ≤ A_HB
        且  三条 paired bootstrap（B=10,000, seed=20261106）
            差值 95% CI 的【上界】均 ≤ 0
```
若 ≥1 个合格：**取 `L_k` 最小者**（并列取 CVaR 更小者）。若 **0 个合格**：如实报告「三候选皆不可」，**不换基线、不放宽 CI、不挑子集、不存在 v1.1**。

另**描述性**报告各候选相对 `CERT-GATE` 的 L/CVaR/A（不作判定）。
