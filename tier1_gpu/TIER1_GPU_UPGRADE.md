## 3. GPU 训练端：三级计算阶梯

### Stage A｜从零监督训练（真正补上的一环）

| 项 | 规格 |
|---|---|
| 语料 | 6 个带标签训练语料（PTB-XL / CSN / CPSC / SPH / CODE-15% / CODE-II-open） |
| 架构族 | ① InceptionTime ② ResNet-1D ③ **仓库已有 `mambapy` / `mamba_chunked.py` 路径，正式纳入受控网格**（纯 PyTorch、无需 CUDA kernel；原仓库 README L103 已声明该 arch 存在但不进 60 格）④ ECGFounder-RegNet（从零，非加载权重）⑤ **CNN–SSM–Attention 混合骨干** [citation:15] |
| 标签本体 | 5 超类（NORM/MI/STTC/CD/HYP）/ CPSC 9 类 / Chapman 4 类 / CODE 66 类，**四套映射表 + 心内科复核** |
| 种子 | **5 个（42–46）**，与原仓库对齐 |
| 网格 | 6 语料 × 5 架构 × 5 种子 = **150 次独立训练** |
| 训练 | 30 epochs、batch 256、AdamW、AMP bf16、cosine、gradient checkpointing、早停按**患者级验证折** |
| 产物 | 150 个 checkpoint + **150 份 logits 缓存** + 训练曲线 + 环境/权重哈希 |

**统一输入**：导联按名对齐到 `{I,II,III,aVR,aVL,aVF,V1–V6}`，重采样 500 Hz、固定 10 s；CODE-II 的 DIII/AVR/AVL/AVF 是**由 8 个基本导联按标准方程重建**的，必须按名而非通道下标读取 [citation:2]。

### Stage B｜基础模型适配（冻结 / 微调 / 线性探针）

| 项 | 规格 |
|---|---|
| 开放权重 | **ECGFounder**（NEJM AI 2025，Hugging Face `PKUDigitalHealth/ECGFounder`，MIT，须严格照其 `dataset.py` 预处理）、**ECG-FM**（MIT，wav2vec2.0 + WCR）、**HuBERT-ECG**、**xECG**（xLSTM）[citation:4][citation:8][citation:9][citation:13] |
| 三种模式 | frozen 线性探针 / 全参微调 / LoRA |
| 外部语料 | PTB-XL、CODE-test、CPSC2018（**互不与训练语料重叠**） |
| 网格 | 4 模型 × 3 模式 × 3 语料 × 3 种子 = **108 次适配** |
| 可选最贵项 | 在 CODE-II 2.7M 上做**一次 Mamba-2 自监督预训练**（JEPA / WCR）—— 参见 ECG-FM 用 8×A100 约 10 天、或 4×A100 80GB 16.5 天的公开量级 [citation:8][citation:13] |

**算力观感**：不要被「预训练 10 天」吓住。HuBERT-ECG 报告**全参微调在单张 A100 上 <2.5 小时** [citation:9]；ECGFounder 原训练是 20 epochs、batch 1024 [citation:4]。**一区不需要我们复现一个千万级基础模型**，需要的是「多架构 × 多语料 × 多种子」的受控训练网格 + 真实 logits。

### Stage C｜校准层（CPU，零 GPU，W1–W12 原封不动）

所有 Stage A/B 的 logits 缓存进入 `CACHE_SCHEMA.json` 契约，之后：

- W6 CERT-GATE、W9 命题 2、W11 T1–T4 **原样重跑**
- **混合漂移可识别性**（W11 明确移至 W12 的那一项）：标签语义 / 患病率 / 设备 / 导联本体同时变时，给出可证伪推论与 BBSE 先验校正项
- 9 指标链、连续部署损失 + CVaR、patient-block / 中心簇 bootstrap、Holm、DCA、亚组交互、360 条断言复跑

**「零 GPU」只指 Stage C**，这点已写死进 README 与预注册。

## 4. 算力预算（工程粗估，必须用你机器上实测吞吐替换）

`grid_planner.py` 用**显式可调吞吐参数**做敏感性分析，不假装精确：

```
GPU-hours = Σ_runs (corpus_records × epochs) / throughput(samples/s) / 3600
```

**按每次运行各自的语料规模累加**（初版曾误把全队列 ×30 当作 150 次，已修正并留痕）。真实执行结果：

| 吞吐假设 | Stage A 150 次训练 | Stage B 108 次适配 | 一次性冻结前向（331 万条） |
|---|---|---|---|
| 500 samples/s | **≈ 191.8 GPU·h** | ≈ 4.7 GPU·h | ≈ 1.84 GPU·h |
| 1,000 samples/s | ≈ 95.9 GPU·h | ≈ 2.4 GPU·h | ≈ 0.92 GPU·h |
| 2,400 samples/s | ≈ 40.0 GPU·h | ≈ 1.0 GPU·h | ≈ 0.38 GPU·h |

> **表格里的数字是公式输出，不是实测结果**，已在 `results/grid_plan.json` 标为 `assumption_driven: true`。真实瓶颈几乎总是 WFDB/HDF5 解码、300/400/500/600/1000 Hz 混合重采样、带通/陷波、z-score、以及把 331 万条写进缓存的 I/O。**吞吐参数必须在你机器上实测后替换。**

对照公开量级：ECG-FM 自监督预训练用了 **8×A100 约 10 天**（另一记录为 4×A100 80GB、16.5 天）[citation:8][citation:13]；HuBERT-ECG **全参微调单张 A100 <2.5 小时** [citation:9]；ECGFounder 原训练 20 epochs、batch 1024 [citation:4]。**一区不需要我们复现一个千万级基础模型**，Stage A 的 150 次受控训练网格在 40–192 GPU·h 量级，单卡数天到集群一天即可完成。

**实用建议**：单卡 A100/4090 起步做 Stage A 的一个子集（3 语料 × 3 架构 × 3 种子 = 27 次），验证管线后再上集群；Stage B 全部单卡可完成；只有可选的自监督预训练需要 8 卡多天。**仍然不需要买卡。**

## 6. 理论落地

- 命题 1（`σ²<τ² ⟺ 分群优于全局`）、命题 2（异方差 BLUP / Jensen）、T1–T4 四条定理，**从合成 logits 搬到真实 logits**逐条验收；失效即按停止条件如实发表
- **T2 界在合成区间 93.4% 平凡**这个已知弱点，正好用 331 万条真实数据检验是否变紧——这是真实数据能回答、合成数据回答不了的问题
- 混合漂移可识别性：给出 `X_g` 偏差非零均值的可证伪推论，**不包装成定理**（W11 教训）

## 11. 诚实边界

- 本文件是**规格与工程骨架**，不是已完成的科研成果；所有 GPU 训练结果均不存在
- 语料规模来自公开发布页/论文 [citation:2][citation:3][citation:7][citation:11][citation:15][citation:16]，**CODE-II 申请是否获批、Georgia 的 DSP 适用性、各语料标签本体映射，均需逐项复核**
- 算力数字是公式粗估，吞吐参数为占位假设，**必须以你机器实测替换**
- 使用开放模型权重不涉 PhysioNet DUA；MIMIC-IV-ECG / HEEDB 仍受 credentialed DUA 与 DOJ DSP 约束；CODE-II 走的是自己的学术申请
- 合规部分不构成法律意见
- W1–W14 均为内部实验，不得写成已发表算法或 SOTA；分区以单位认定最新名单为准
