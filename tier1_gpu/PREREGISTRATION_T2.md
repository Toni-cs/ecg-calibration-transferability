# 预注册 T2｜一区级 GPU 训练端（冻结）

**版本**：v1.0（终局）
**冻结时间**：2026-11-06（Asia/Shanghai）
**性质**：**在接触任何真实波形前向之前冻结**。W1–W11-B 的预注册全部保留、不被替换。
**适用**：Stage A / Stage B / Stage C 全链；W14-A～W14-D。

---

## 0. 研究问题（冻结）

在**多国多中心、混合漂移（采集协议 + 导联本体 + 标签本体 + 患病率同时变）**下，源域拟合的 post-hoc 温度缩放能否迁移？若不能，可观测部署元数据驱动的**群结构化校准 + 部署证书**在真实波形训练出的 logits 上是否仍成立？

**与 W1–W12 的关系**：W1–W12 是合成层 / 协议级内部实验（CPU、NumPy、toy 波形）。T2 把它们**原封不动**搬到真实 logits 上，不新增指标、不换 estimand、不事后改阈值。

## 1. 数据（冻结）

### 1.1 主队列
- **公开层 12 语料**（PTB-XL / CSN / CPSC2018 / CPSC-Extra / SPH / Georgia / CODE-15% / IKEM / SaMi-Trop / CODE-test / CODE-II-open / MIMIC-IV-ECG-Demo），≈574,600 记录 / ≈39.1 万患者
- **CODE-II 全量**（学术申请，2,735,196 记录 / 2,093,748 患者，巴西）
- **主队列合计 ≈331 万记录 / ≈248 万独立患者 / ≥8 国**

### 1.2 不进承诺
MIMIC-IV-ECG（PhysioNet credentialed，DOJ DSP 对华限制）、HEEDB（BDSP DUA）、CODE 全量。仅作增量，明确写「未纳入」。

### 1.3 重叠规则（事前写死）
- CODE-15% ⊂ 旧 CODE（2010–2016）；CODE-II 为 2019–2022 新队列，二者不重叠
- 若同时取得 CODE 全量，按 `exam_id` + `patient_id` 去重，不得重复计数
- PTB-XL / CSN / CPSC 与原 60 格 pilot 重叠 → 仅作标签本体压力测试与外验，**不重复计入总量**

### 1.4 统计单元
**患者**，不是记录。所有切分按 `patient_id` 严格不相交；bootstrap 按 patient-block + 中心簇双层级；`deff = 1+(m̄−1)·ICC`、`n_eff = n/deff`。

## 2. 预处理（冻结）

1. 导联**按名**对齐到 `{I,II,III,aVR,aVL,aVF,V1–V6}`；MIMIC aVF/aVL 互换、CODE-II 的 DIII/AVR/AVL/AVF 由 8 基本导联重建，**禁止按通道下标读取**
2. 统一重采样 500 Hz、固定 10 s；记录原始采样率（300/400/500/600/1000 Hz）作为部署元数据
3. 带通 0.5–50 Hz + 60 Hz 陷波 + z-score；**ECGFounder 权重必须严格按其 `dataset.py` 预处理**，否则结果不可比
4. CODE-15% 的 **173,347 条（50.13%）既非六类异常也非 normal，绝不当 confident negative**；只用 `normal_ecg` 作干净负例
5. 标签本体四套（5 超类 / CPSC 9 类 / Chapman 4 类 / CODE 66 类）映射表**由心内科合作者复核签字**后方可使用

## 6. 主终点与验收门（跑之前写死）

### 6.1 主终点
**跨外验折的连续部署损失 L + 各自 CVaR₀.₁% + 平均 ΔECE**，要求相对 SOURCE / GLOBAL / GST 三者**三不劣**且三条 CI 上界 ≤ 0。

### 6.2 12 条验收门

| ID | 判据 | 阈值 |
|---|---|---|
| G01 | F0 有效性：ORACLE 的 NLL 不劣于所有估计器 | 100% 折通过 |
| G02 | 主终点三不劣 | 三条 CI 上界 ≤ 0 |
| G03 | CVaR₀.₁% 改善 | paired CI 上界 ≤ 0 |
| G04 | 平均 ΔECE 改善 | paired CI 上界 ≤ 0 |
| G05 | 12 类 LOCO 中至少 10 类不劣 | ≥10/12 |
| G06 | 命题 1 在真实 logits 上成立 | 证书判定与 DGP 真值一致率 ≥0.80 |
| G07 | 命题 2 在真实 logits 上成立 | Jensen 差额 ≥0 且数值格 ≥95% |
| G08 | T2 界非平凡比例 | >10%（合成层仅 6.6%，须改善） |
| G09 | 患者级 deff / ICC 与理论一致 | deff ≥1、n_eff/n ≤1、ICC ∈ [0,1] |
| G10 | 360 条断言复跑 | ≥354/360，FAIL 逐条留痕 |
| G11 | 架构族间方向一致 | 5 个架构族同号 ≥4 |
| G12 | 第三方独立复跑 12 门 | 12/12 |

**G08 是合成层已知弱点的直接检验**：W11 的 T2 界 93.4% 平凡、保守约 100×；真实 331 万条能否把界拉紧，是真实数据能回答而合成数据回答不了的问题。**若仍平凡，如实写「界有效但不可用」，不包装。**
