## 0. 口径声明：6 万种子能补什么、不能补什么

**先说不能的**（避免自相矛盾）：W6 已明确论证，1 区要的是**七个维度**（真实百万级队列、患者级统计、完整指标链、非 in-sample 外验、理论、部署证书、外部背书），不是种子数。**60,000 个合成种子不能替代其中任何一个。** 再堆 6000 个种子重复证明主效应，边际收益仍然是零。

**能补的**（本轮唯一价值）：600 种子对危害率的二项 SE ≈ 1.3%，**看不见 0.1% 级的稀有失效**。60,000 种子把 SE 压到 ≈0.05%，从而能回答一个全新问题：

> **部署证书在连续异质性全域上，什么时候以什么条件失效？最坏的 0.1% 场景长什么样？**

具体新增：
1. 危害率 **CI 半宽 ≤0.0015**（600 种子做不到）
2. **spread 连续 Uniform(0.05, 1.50)**，而非 W6 的 A/B 两档 → 画出证书准确率 / 危害率随异质性的精细曲线，定位命题 1 的决策边界
3. **高维分层**：λ 五分位 × spread 三分位 × 最小群规模三分位 → 找最高风险格（直接回应 W6 H4「全局证书 vs 局部异质」）
4. **尾部 0.1%（60 个最差种子）系统画像** → 部署尾部风险证据
5. **跨轮次可复现性**：60k 的 CI 是否覆盖 W6 的 600 种子点估计 0.0133
6. **6,000 个 CNN-1D 种子**（占 10%）→ 架构一致性在大样本下的检验

**W6 的 600 个确认性种子结果一个不改、一个不删。** W7 是第 8 个补充维度（统计精度 / 稀有事件图谱），不是替代品。

## 3. 估计器（6 个，全报）

`SOURCE` / `GLOBAL` / `GST` / `SR-GST` / `GS-GST` / `CERT-GATE`

`CERT-GATE`：`τ̂² = max(Var(log T̂_g) − mean(1/n_g), 0)`，`σ̂² = mean(1/n_g)`；`τ̂² ≤ σ̂² ⇒ 回退 GLOBAL`，否则用 λ 收缩。`λ = τ̂²/(τ̂²+σ̂²)`，**零超参**。

**harm 判据**（沿用 W6）：`ECE_k > ECE_GLOBAL + 0.002`。0.002 是事前非劣容差，避免分箱估计量微小抖动被记成危害。

## 4. 事前判据（冻结）

| ID | 判据 |
|---|---|
| **P0（桥接）** | 600 个 W6 原口径种子的 `harm(CERT-GATE)` 与 `harm(GST)` 方向、相对关系与 W6 一致（≤0.025 / ≥50% 下降） |
| **P1（精度）** | 全 60,000 上 `harm(CERT-GATE)` 的 95% CI **半宽 ≤ 0.0015** |
| **P2（主效应）** | `harm(CERT-GATE) ≤ 0.025`，**且**相对 `harm(GST)` 下降 ≥50%，**且** paired bootstrap（单位=种子，B=10,000）差值 CI 下界 > 0 |
| **P3（稀有失效格）** | 事前声明的高风险格 = **λ 最低五分位 × spread 最低三分位 × n_min 最低三分位**；其条件危害率 ≥ 全体危害率的 **3 倍**（且该格 ≥200 种子） |
| **P4（跨轮次复现）** | 60k 的 `harm(CERT-GATE)` 95% CI **包含 W6 点估计 0.0133** |
| **P5（尾部 0.1%）** | 最差 60 个种子（按 `dECE_CERT`）中，证书判 GST 的比例 **≤ 全体比例**（证书在最坏场景不应更倾向分群） |
| **P6（架构）** | 6,000 CNN 种子的 `mean dECE_CERT` 与 54,000 Mamba **同号且 ≤ −0.002** |
| **P7（命题 1 精细验证）** | 证书准确率随 spread 单调：20 个等宽 spread 箱上 Spearman ρ ≥ 0.8；且判 GST 比例在 `τ̂²/σ̂² ≈ 1` 附近最陡 |

**F0 有效性门槛**（先于一切结果）：
1. 操控有效性 `mean(ECE_SOURCE − ECE_GLOBAL) > 0.02` 且 ≥90% 种子为正
2. `mean(ECE_ORACLE_upper_proxy)` 不适用（轻量口径无 ORACLE）；改用 `mean(ECE_GST) ≤ mean(ECE_GLOBAL)` 的**方向一致性** ≥60% 种子
3. 任一不满足 → 全部作废，修实现后重新冻结

## 5. 统计口径

- **所有主判据抽样单位 = 种子**（W2 v1.0 单位错配的教训）
- 主 CI 用 **Wilson 区间**（二项率，60k 下正态近似亦一致，两个都报）
- paired bootstrap B=10,000，固定 seed=20261106
- 分层分析：spread 20 等宽箱、λ 五分位、n_min 三分位、ICC 三分位；**所有格即使不利也报告**
- 尾部 0.1% 定义为 `dECE_CERT` 最大的 60 个种子，逐条保存
- 6,000 个种子是独立 DGP 抽样，**不是** 6,000 个患者或中心；明确标注

## 7. 诚实边界

- 合成 12 导联 toy 波形 + 对角 selective SSM（numpy 近似）+ 层级漂移代理，**不是**官方 Mamba-2 CUDA kernel、不是预训练权重、不是真实 1.15M ECG
