## 2. E1 识别性：函数可识别，但方法不独占

- `Ψ_P(T)` 单峰、唯一内部极小；5% 容忍带 `T` 宽度 **0.84**
- `T_hat_PARI = 2.3676`，`T_hat_POOLED = 2.3676`，真实 `τ_t = 2.4`（偏差 −0.032）

**两个估计量给出逐位相同的答案。** 这说明「重复测量配对」在这个 DGP 里没有提供任何 pooled 拿不到的信息。可识别 ≠ 有新方法。

## 3. E2–E4 方差缩减：没有一致优势

| n_pat | PARI RMSE | POOLED RMSE | 增益比 |
|---|---|---|---|
| 25 | 0.1722 | 0.1423 | 0.83× |
| 100 | 0.0958 | 0.0800 | 0.84× |
| 200 | 0.0536 | 0.0528 | 0.99× |
| 400 | 0.0400 | 0.0485 | 1.21× |
| 800 | 0.0283 | 0.0297 | **1.05×** |

- 增益比全距 **0.83–1.21×**，无单调趋势；`n=800` 仅 1.05×
- 收敛斜率：对 `n_pat` **−0.544**，对 `n_pat·m` **−0.556**（理论 −0.5）——两者速率相同，配对没有改变收敛阶
- 轨道深度 m=2/4/8：两者同样下降，无差异化

**结论**：上一版写的「`O_p((n_patient·m̄)^{-1/2}·κ(G))` 且优于无配对估计」这一强主张，**未获支持**。

## 4. E3 四个证伪检验：两个通过、一个暴露更深的缺陷

| ID | 操作 | 结果 |
|---|---|---|
| F1 | 打乱患者配对 | ✅ 增益消失（RMSE 回到 pooled 水平） |
| F2 | 打乱群标签 | ✅ 估计退化（>1.5× 基线 RMSE） |
| F3 | 单记录患者 | 配对不可定义 → 确定性 fallback 到 pooled（逻辑结论，非数值实验） |
| F4 | **阵发性标签（破坏 A1）** | ❌ **没有退化** |

**F4 是本次最该重视的发现**：PARI 对「患者内标签稳定」这条核心假设根本不敏感。也就是说 A1 不是该估计量的有效识别条件，理论部分必须重写或删除。这比方法没跑赢基线更致命。

## 5. D1–D4 机制诊断：找不到 PARI 占优的区间

| 实验 | 变量 | 增益比 |
|---|---|---|
| D1 轨道长度不均衡 | 0 / 0.25 / 0.5 / 1 / 2 | 1.00 / 1.06 / 0.91 / 0.99 / **1.09×** |
| D3 患者原型异质性（平衡对照） | 0.05–0.50 | **恒为 1.00×** |
| D4 **信息性轨道长度**（病情重 → 记录多） | 0.5 / 1 / 2 | 0.94 / 0.86 / **0.83×（PARI 更差）** |

D4 里确实出现了预期的偏差机制：PARI 偏差 **+0.0010~+0.0022**（近似无偏），POOLED 偏差 **−0.0057~−0.0108**（有偏）。但**配对用更大的方差换来了无偏性**，RMSE 反而更差。

**裁定（按预注册失败条款）**：
> 在可交换患者原型这一 DGP 族下，患者锚定估计量并不是比简单 pooled 直方图匹配更好的全局温度估计器。**PARI 原版降级/放弃，不得作为 T1 论文的 novelty 主张。** 是否真实 1M 队列落在这一族之外，是必须在 T1 事前注册检验的经验问题，不能靠调 DGP 救回来。

我没有继续调参数去找「好看的区间」——那正是这个项目历史上已经吃过亏的 HARKing。

## 6. 唯一存活的正面结果：E5，而且它支持的是「问题」不是「解法」

群间真实温度离散度 s 从 0 → 1.2 时，强制使用**单一全局 T** 的平均校准后悔从 **0.0005 → 0.1557**。

这条干净地复现了原项目的核心现象：**源域拟合的温度搬不过去**。它给 BCC 的 per-group / 三态决策提供了动机，但它不是新方法。
