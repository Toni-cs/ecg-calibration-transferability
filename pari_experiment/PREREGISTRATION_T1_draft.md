## 1. 已完成的先验证据（W1，不得事后修改）

| 结果 | 数值 | 含义 |
|---|---|---|
| 识别性 | `T_hat_PARI = 2.3676`，`T_hat_pooled = 2.3676`，真实 `τ_t = 2.4`；Ψ 单峰，5% 容忍带宽 0.84 | 目标函数**可识别**，但 PARI 与 pooled 给出**完全相同**的估计 |
| 方差缩减 | 增益比 0.83–1.21×，`n=800` 时仅 1.05× | 无一致优势 |
| 收敛率 | 对 `n_pat` 斜率 −0.544，对 `n_pat·m` 斜率 −0.556（理论 −0.5） | 两者收敛速率相同，配对未改变速率 |
| 证伪 F1/F2/F4 | True / True / **False** | 打乱配对、打乱群标签能破坏估计；但**破坏 A1（阵发性标签）不会使其退化** → 该估计量对 A1 不敏感，A1 不是有效识别条件 |
| 机制诊断 D1/D3/D4 | 1.00× / 0.91–1.09× / **0.83–0.94×（PARI 更差）** | 不均衡轨道与信息性轨道长度都不产生优势；D4 中 PARI 偏差 +0.001 vs pooled −0.010（无偏），但方差更大，RMSE 更差 |
| 群异质性 E5 | 单一全局 T 的校准后悔 0.0005 → **0.1557** | **问题成立**：群间温度漂移让单温度不可搬运 |
| 本地数据 E0 | 公开树无逐记录 logits/probs，无波形 | 真实数据 PARI 复现被 DUA + 波形前向卡住 |

**裁定**：按 W1 失败条款，**PARI 原版降级/放弃，不得作为 T1 论文的 novelty 主张**。E5 的问题结论保留。

## 2. T1 的主问题（重新表述）

> 在 1,145,814 条记录、≈395,122 名患者的两国队列里，**是否真实存在**
> 「患者内重复测量轨道携带、而记录级混合估计量无法利用」的校准信息？

这是一个**经验问题**，不是可以用合成 DGP 断言的理论问题。W1 已证明：在交换able 患者原型下答案倾向「否」。T1 的第一件事是检验真实数据是否落在 W1 否证的类之外。

## 4. 事前注册的终点与阈值

### 主终点 H1（kill-switch）
在真实数据上，患者配对估计量相对记录级 pooled 的 **OOD ECE 改善**：
- **通过**：≥ **0.02** ECE，且 12-stratum patient-block BCa 95% CI 下界 > 0
- **不通过**：按失败条款，**PARI 彻底放弃**；论文改以 E5 的问题结论 + BCC 证书 + 1.15M 系统性验证为主体，novelty 声明相应收窄；不得换指标、换子群、换分箱数救结论

### 次要终点（全部事前固定）
| 终点 | 阈值 |
|---|---|
| H2 群间温度漂移幅度 | 报告 `cart_id` / site / 年份分层的拟合 T 分布与 I²，不作显著性宣称 |
| H3 单一全局 T 的部署后悔 | 复现 E5 曲线；后悔 > 0.05 则支持 per-group / 三态决策 |
| H4 BCC 有限样本证书 | 给出非真空上界；**若证明不成立，明确降级为「经验证书、无理论保证」** |
| H5 最小标注预算 | `n̂_cal` 与真实饱和点 MAE ≤ 1 个预算档（8/16/32/50/100/250/500/1000） |

### 分层（事前声明，禁止事后挑选）
慢性/结构性诊断 vs 阵发性（AF、阵发室上速）；site；`cart_id`；年份；导联子集；采样率；性别/年龄组（若可得）。**阵发层必须单独报告，即使结果不利**。
