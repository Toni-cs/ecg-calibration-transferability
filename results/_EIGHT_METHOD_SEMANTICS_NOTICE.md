# `_EIGHT_METHOD_SEMANTICS_NOTICE.md` — the historical shared-correctness semantics of the delivered 8-method table

**Status:** software fixed 2026-10-11 (`scripts/eval_transfer.py` + `src/utils/calibration.py`, ledger A12); this notice is the *labeling layer* for the already-delivered CSV so no delivered byte is modified.
**Read this before quoting any non-`ts` row of `results/robustness_validation_5seeds.csv` (or of the manuscript's 8-method section).**

## 1. The exact historical semantics

For every one of the 480 delivered rows (8 methods × 60 cells), the historical
driver computed the paired bootstrap with **ONE correctness vector shared by
both bootstrap branches**:

- **calibration branch** correctness = `(argmax(calibrated_probs) == y)` — the _calibrated_-argmax mask —
- **raw branch** correctness = **the same calibrated-argmax mask** (not the raw model's own argmax).

Correct behavior (shipped 2026-10-11) computes the raw branch against the
_raw_-argmax mask (`labels_raw` in `benefit_inference`).

## 2. Who is affected

- **Unaffected, exactly:** `ts` (argument-preserving by construction; calibrated and
  raw argmax are identical → the two semantics coincide numerically). This is why
  the primary endpoint is immune. Also any shared-(a,b) Platt variant where
  `a > 0`.
- **Affected (argmax can flip):** per-class Platt (`platt`), `isotonic`, `vector`,
  `matrix`, `dirichlet`, `em_prior`, `bbse_prior` — 7 of the 8 delivered methods.
  For these, raw-branch ECE in the delivered rows is measured against the
  calibrated-argmax correctness, which mis-measures exactly the records the
  calibrator moved.

## 3. How big is the effect (measured, not speculated)

The delivered numbers were re-derived from the cached probability arrays under
correct per-branch semantics in
`results/robustness_val_8method_perbranch_recheck.csv`
(generated by `scripts/recheck_method_semantics.py`; ledger A15 — TS gate 60/60
exact, 0 argmax flips). Per-method OOD mean ΔECE (delivered → per-branch):

| method | delivered | per-branch | shift |
|---|---|---|---|
| ts | +0.0093 | +0.0093 | 0 (exact) |
| platt | +0.0092 | +0.0086 | −0.0006 |
| isotonic | +0.0035 | +0.0024 | −0.0011 |
| vector | +0.0082 | +0.0088 | +0.0006 |
| matrix | +0.0045 | +0.0072 | +0.0027 |
| dirichlet | +0.0053 | +0.0069 | +0.0017 |
| em_prior | −0.0040 | **−0.0378** | −0.0338 |
| bbse_prior | +0.0270 | +0.0172 | −0.0099 |

Qualitative reading: **no paper claim flips**; the EM-prior claim is *stronger*
under correct semantics (−0.0378), BBSE remains the positive counterpoint, and
the parametric methods shift within ±0.003.
