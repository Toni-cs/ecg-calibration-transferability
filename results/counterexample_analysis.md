## 4. TS方法失效条件分析

### 4.1 失效条件可预测性

基于6个反例的共同特征，TS方法的失效条件**可以预测**:

**预测规则**: 当以下3个条件同时满足时，TS方法大概率失效（ΔECE_OOD < 0）:
1. **decay < 0**: OOD校准收益小于ID校准收益
2. **OOD accuracy接近随机基线**: 模型在OOD上无判别力（4类<0.5，5类<0.4）
3. **ID-OOD性能gap大**: ID accuracy远高于OOD accuracy（gap > 0.18）

**物理机制解释**:
- 当模型在OOD上接近随机猜测时，softmax输出概率分布接近均匀
- 温度缩放对接近均匀的分布调整能力有限（温度T对均匀分布无影响）
- 此时ID上拟合的温度T*无法有效改善OOD校准
- 导致OOD cal ECE ≥ OOD raw ECE，即ΔECE_OOD < 0

### 4.2 C4贡献评估

**反例可预测性对C4（方法选择边界）的贡献**:

| 维度 | 评估 | 强度 |
|------|------|------|
| 失效条件可识别 | ✓ decay<0 + 低OOD Acc + 大ID-OOD gap | 强 |
| 失效机制可解释 | ✓ 温度缩放对均匀分布无效 | 强 |
| 失效边界可划定 | ✓ 可预先检测OOD Acc判断是否适用TS | 中 |
| 失效非随机 | ✓ 5/6反例符合典型画像 | 强 |

**结论**: 反例的**可预测性是C4（方法选择边界）的强贡献**。TS方法在"低OOD判别力"条件下系统性失效，这一边界可预先识别。

## 6. 最终结论

### 6.1 6个反例是随机噪声还是系统性问题？

**结论: 部分系统性，但非致命系统性问题**

**系统性证据**:
1. 6/6反例decay全部为负（100%）: 非随机
2. 5/6反例OOD accuracy < 0.5（83.3%）: 非随机
3. 5/6反例符合"低OOD判别力"画像: 非随机
4. 反例机制可解释（温度缩放对均匀分布无效）: 非随机

**非致命证据**:
1. 反例率12.5%: 可接受范围
2. 反例量级小（4/6 < 0.003）: 影响有限
3. 反例可预测: 可预先识别并规避
4. 反例未集中在主要方向: 不影响核心论证
5. 反例对C2/C4有正向贡献: 整体不削弱论文

### 6.2 对2区达标的影响

**影响评估: 可接受，非致命**

| 维度 | 影响 | 严重性 |
|------|------|--------|
| C1（主终点） | 87.5%支持，轻微削弱 | 低 |
| C2（ID边界） | 反例支持（\|ΔECE_ID\|小） | 正向 |
| C4（方法边界） | 反例强化（可预测失效） | 正向 |
| 主要方向 | ptbxl_cpsc零反例，chapman_cpsc 80%支持 | 低 |
| 反例量级 | 4/6 < 0.003，无大量级 | 低 |
| 反例可预测 | 5/6符合典型画像 | 正向 |

### 6.3 综合判定

**6个反例是"可预测的边界失效"，非"随机噪声"，也非"致命系统性问题"**:

1. **非随机噪声**: 反例有明确的共同特征（decay<0 + 低OOD Acc + 大ID-OOD gap），符合可预测的失效模式
