# W8 诊断报告｜绝对群规模门在当前合成 DGP 上退化（负面结果，完整保留）

**日期**：2026-11-06
**预注册**：`PREREGISTRATION_W8.md` v1.0（冻结后执行）
**性质**：**探索性诊断**。W8 **未消耗任何确认性种子**；110000–120599 全部留给 W9。
**结论**：事前写死的第二道门用绝对 `n_min` 作统计量，在当前 DGP 上**无分辨力**；规则逐字执行后 `n*=8`（门恒开），DG-CERT ≡ CERT-GATE。这是**设计失效**，不是方法成功。

---

## 1. 逐字执行了什么

`explore_w8.py` 按预注册 §2 的规则，从 W7 的 60,000 条原始分片（143 个 npz，21000–80999）计算候选网格 `{8,12,16,20,24,30,40,60,80}`：

| n* | 允许分群比例 | harm | gain | 合格（gain ≤ −0.010） |
|---|---|---|---|---|
| **8** | **65.6%** | **0.02340** | **−0.01717** | **✅** |
| 12 | 0.0% | 0.00000 | −0.00000 | ❌ |
| 16–80 | 0.0% | 0.00000 | 0.00000 | ❌ |

`Q = {8}`，规则「argmin harm over Q，并列取最小 c」→ **`FROZEN_N_STAR = 8`**。已写入 `W8_FROZEN_GATE.json`，不可更改。

**`n*=8` 等于门恒开**：`use_split = cert==1 AND n_min>=8`，而 `n_min >= 8` 恒成立 ⇒ DG-CERT 逐位等于 W7 的 CERT-GATE。**H1（危害降 ≥50%）按构造不可能成立**，跑 10,000 个确认种子得不到任何新信息。

## 2. 为什么会这样（真正的发现）

`hierarchical_groups` 里群规模有硬下界 `np.clip(..., 8, None)`，而 W7 的 `n_total=1000`、36 群 ⇒ **99.99% 的场景 `n_min` 恰好等于 8**：

```
n_min 唯一值数 = 5 ，分位数 [8, 8, 8, 8, 8, 8, 12]
```

绝对规模阈值在一个被 clip 到常数的量上**没有任何分辨力**。更糟的是，`gain_c ≤ −0.010` 这条防退化约束恰好把唯一有分辨力的候选（n*=8，即恒开）选了出来，而所有真正会回退的候选都因 `gain≈0` 被判不合格。

**P3 的教训在 W8 以另一种形式重演**：`harm` 相对 GLOBAL 定义，「永远回退」会让 harm 恒为 0；这次是「永远不回退」让 gain 保住。任何单参数硬门都在这两个极端之间摆动。

## 3. 换成相对不均衡度 `imb = n_min/n_max` 会怎样

`imb` 有 140 个不同取值，分位数 `[0.012, 0.044, 0.056, 0.070, 0.085, 0.099, 0.179]`。在 W7 探索集上扫阈值：

| imb ≥ | 允许分群 | harm | gain |
|---|---|---|---|
| 0.02 | 65.6% | 0.02340 | −0.01716 |
| 0.04 | 61.6% | 0.02197 | −0.01610 |
| 0.06 | 45.4% | **0.01660** | **−0.01183** |
| 0.08 | 22.6% | 0.00850 | −0.00587 |
| 0.10 | 6.4% | 0.00272 | −0.00161 |
| ≥0.15 | 0% | 0 | 0 |

按同一规则，合格集 `{0.02, 0.04, 0.06}` → 选 0.06，危害只降 **29%**，**达不到 H1 要求的 50%**；要降 64%（imb≥0.08）就得把平均增益丢掉 66%。

> **这条权衡是 W8 最值钱的产出：在「不牺牲平均校准增益」的约束下，任何单参数硬门最多只能把部署危害压掉约三成。硬门不是正确形式。**

## 4. 由此得出的设计结论（W9 的依据）

1. 第二道门**不能用绝对规模或硬阈值**：前者在合成层退化，后者在「保增益 / 降危害」间做零和取舍
2. 需要一个**连续、零超参、由估计量自身不确定性驱动**的可靠性量：估计越不稳，收缩越强，而不是二值回退
3. 候选：λ 的 **leave-one-group-out jackknife 下界** `λ_LB = clip(λ − 1.96·SE_jack, 0, 1)`——完全无标签、无阈值、无可挑参数，且直接对应 P5 的「证书判可分群但估计不可靠」
4. 用它**替代** λ 作为收缩系数（而非新增第二道门），命题 1 的第一道门自然包含其中：`τ̂² ≤ σ̂² ⇒ λ=0 ⇒ λ_LB=0 ⇒ GLOBAL`

**W9 据此另起一份新预注册，用全新种子确认。W8 不修订、不补种子、不换规则、不存在 v1.1。**
