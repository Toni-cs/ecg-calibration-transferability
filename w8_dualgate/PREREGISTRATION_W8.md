## 0. 为什么这是「继续优化」而不是「再刷一轮」

W7 已把统计精度做到 CI 半宽 0.00121，再加大种子数没有新信息。W6/W7 三项未过判据指向同一个缝：

| 来源 | 发现 |
|---|---|
| W6 H4 | 三类 LOCO 上全局证书漏掉局部异质（0.60–0.65 < 2/3） |
| W7 P3 | 真正高风险格是 **λ 中间层 × 低异质 × n_min 低**（4.25%，1.8× 全体） |
| W7 P5 | 最差 60 个场景 **100% 判 GST**，全体仅 65.61% |
| W4 F4 | 危害来自小 calibration split 过拟合，不是群漂移 |

**共同结论**：第一道门（`τ̂² > σ̂²`）只判断「平均而言该不该分群」，不判断「这个部署的群够不够大、信噪比够不够稳」。W8 补第二道门。

## 1. 方法：DG-CERT（Dual-Gate Certificate）

```
Gate 1（命题 1，W6 已有）:  τ̂² > σ̂²        # 平均异质 > 估计噪声
Gate 2（W8 新增）:          n_min ≥ n*      # 最小部署群规模达标
─────────────────────────────────────────────────
if Gate1 AND Gate2:  T̂_g = GS-GST 的 λ 收缩   # 允许分群
else:                T̂_g = T_global          # 回退，不分群
```

`τ̂² = max(Var(log T̂_g) − mean(1/n_g), 0)`，`σ̂² = mean(1/n_g)`，`λ = τ̂²/(τ̂²+σ̂²)`。**零可调超参**（n* 由 §3 的事前规则从探索集唯一确定，不是在本轮数据上挑的）。

**不声称**：首次门控、首次收缩、首次分域温度。边界 = 首次把 W7 的 0.1% 尾部失效机制转成可证明的第二道可靠性门，并在独立种子上验证。

**同时探索性报告 `λ_LB`**（leave-one-group-out jackknife 的 λ 下界 `λ − 1.96·SE_jack`），**主判据只用 n_min 门**。理由：单参数门避免在两个自由度上挑阈值（HARKing）；λ_LB 留作 W9 的候选，本轮不作任何判定。

## 2. 选门规则（事前冻结，无任何确认集信息）

**探索集 = W7 的 60,000 条逐场景原始分片**（已落盘，`w7_60k/shards/`）。仅用于确定 `n*`，**不参与任何确认性判据**。

候选网格：`N* = {8, 12, 16, 20, 24, 30, 40, 60, 80}`

对每个候选 `c` 定义：
```
use_split(c) = (cert == 1) AND (n_min >= c)
ece_DG(c)    = ece_CERT   if use_split(c) else ece_GLOBAL
harm_c       = mean( ece_DG(c) > ece_GLOBAL + 0.002 )
gain_c       = mean( ece_DG(c) - ece_GLOBAL )        # 负=改善
```

**选择规则（逐字执行，不含人为判断）**：
1. 合格集 `Q = { c : gain_c ≤ −0.010 }`（−0.010 ≈ 保留 W7 基准增益 −0.0172 的 58%；防止门退化成「永远不分群」）
2. 若 `Q ≠ ∅`：`n* = argmin_{c∈Q} harm_c`；**并列取最小的 c**（门尽可能宽松，避免不必要回退）
3. 若 `Q = ∅`：`n* = argmin_c harm_c`，并列取 `gain_c` 最负者；并在报告标注「无合格门」
4. `n*` 一经算出写入 `W8_FROZEN_GATE.json`，附时间戳，**不得更改**

> 关键防退化设计：`harm` 是相对 GLOBAL 定义的，「永远回退 GLOBAL」会让 harm 恒为 0（W7 P3 已踩过这个坑）。所以必须用 `gain_c ≤ −0.010` 同时约束平均校准增益不得丢失。

## 4. 主判据（冻结）

| ID | 判据 |
|---|---|
| **F0** | 操控有效性 `mean(ECE_SOURCE−ECE_GLOBAL)>0.02` 且 ≥90% 种子为正；GST≤GLOBAL 方向一致性 ≥60% |
| **H1（主）** | `harm(DG) ≤ 0.5 × harm(CERT)` **且** paired bootstrap（单位=种子，B=10,000）`harm(CERT)−harm(DG)` 的 CI 下界 > 0 |
| **H2（非劣）** | `mean ΔECE(DG) ≤ mean ΔECE(CERT) + 0.005`（平均校准增益不得因回退而丢失） |
| **H3（尾部修复）** | 在 **CERT 的尾部 0.1%（10 个最大 ΔECE_CERT）种子**上，`mean ΔECE(DG)` 相对 `mean ΔECE(CERT)` 下降 ≥50%；且这 10 个种子里 DG 判分的比例 ≤ CERT 判分的比例 |
| **H4（分层一致性）** | spread 20 等宽箱中，`harm(DG) ≤ harm(CERT)` 的箱数 ≥18 |
| **H5（架构）** | 1,000 个 CNN 种子的 `mean ΔECE(DG)` 与 9,000 Mamba **同号且 ≤ −0.002** |

`harm` 定义沿用 W7：`ECE_k > ECE_GLOBAL + 0.002`（事前非劣容差）。

### 证伪（120000–120599，事前固定）

| ID | 操作 | 预期 |
|---|---|---|
| F1 | `n*=0`（门恒开） | DG **逐位精确**等于 CERT，max 差 < 1e-12 |
| F2 | `n*=∞`（门恒关） | DG ≡ GLOBAL，`mean ΔECE(DG)` = 0 |
| F3 | 随机门（抛硬币） | H1 的优势大幅消失 |
| F4 | `spread=0` 群同质 | DG 与 CERT 差异 < 0.005 |
| F5 | 用 `n_max` 代替 `n_min`（错误统计量） | 优势消失 |
