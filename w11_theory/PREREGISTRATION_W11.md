## 0. 记号与假设（全轮统一，事前冻结）

G 个部署群，目标量 `θ_g = log T_g*`。

- **A1（随机效应）**：`θ_g = μ + a_g`，`a_g` 独立、`E a_g = 0`、`Var(a_g) = τ² > 0`
- **A2（无标签估计）**：`X_g = θ_g + ε_g`，`ε_g` 独立、`E ε_g = 0`、`Var(ε_g) = σ²_g > 0`，与 `a_g` 独立
- **A3（患者重复测量噪声模型）**：`σ²_g = deff / n_g`，`deff = 1 + (m̄ − 1)·ICC`，`m̄ = n_rec/n_patient`，`ICC ∈ [0,1)`。**W11 起 `deff` 正式进入理论**；W6–W9 用 `deff ≡ 1`。W10-M1 用 `deff` 实测均值 1.944。
- **A4（中心已知）**：pooled 中心 `m ≡ μ` 视为已知（`log T_global` 由全目标域置信度直方图拟合，样本量远大于单群）。**这是本轮理论的显式限制**：有限 pooled 中心的误差项不在此界内，见 §7。
- **A5（高斯，仅用于 Chebyshev 的方差闭式）**：`a_g, ε_g` 高斯。`X_g ~ N(μ, v_g)`，`v_g := τ² + σ²_g`，独立但**非同分布**。

估计量：
```
Ŝ²   = 样本方差 var(X_1..X_G, ddof=1)          # E Ŝ² = τ² + σ̄²,  σ̄² = mean σ²_g
τ̂²   = max(Ŝ² − σ̄², 0)                          # method-of-moments，截断
λ̂_g  = τ̂² /(τ̂² + σ²_g)                         # plug-in 异方差 BLUP 权重
λ*_g = τ²  /(τ²  + σ²_g)                        # oracle 异方差 BLUP 权重
λ̄    = τ²  /(τ²  + σ̄²)                          # oracle 同方差 BLUP 权重
```

风险（A4 下精确）：
```
R_g(λ)  = λ²σ²_g + (1−λ)²τ²                 = R*_g + (τ²+σ²_g)(λ−λ*_g)²
R*_g    = f(σ²_g) := τ²σ²_g/(τ²+σ²_g)          # f''(x) = −2τ⁴/(τ²+x)³ < 0
R*_hetero = mean_g f(σ²_g) ≤ f(σ̄²) = R_homo   # W9 命题 2，Jensen
gap    := R_homo − R*_hetero > 0  unless all σ²_g equal
R_hetero(λ̂) := mean_g R_g(λ̂_g)
```

## 1. 四条待验定理（事前写死，不许事后改陈述）

### T1｜超额风险的精确二次分解（确定性，无概率）
```
R_g(λ̂_g) − R*_g = σ²_g² (τ̂²−τ²)² / [ (τ̂²+σ²_g)² (τ²+σ²_g) ]
                ≤ (τ̂²−τ²)² /(τ²+σ²_g) ≤ (τ̂²−τ²)² / τ²
```
**证明要点**：`λ̂−λ* = σ²_g(τ̂²−τ²)/[(τ̂²+σ²_g)(τ²+σ²_g)]`，代入二次分解；`σ²_g ≤ τ̂²+σ²_g` 给出第一处不等式。

### T2｜非渐近 domination 失败界（本轮主定理）
设 `M₂ := mean_g v_g²`，`v̄ := mean_g v_g = τ²+σ̄²`，`V := Var(τ̂² 未截断) = 2[(G−2)M₂ + v̄²]/(G−1)²`。则对任意 `δ > 0`：

```
P( R_hetero(λ̂) > R*_hetero + δ )  ≤  min(1, V/(δ τ²))
特别地，取 δ = gap：
P( R_hetero(λ̂) > R_homo )        ≤  min(1, V/(gap·τ²))        ... (★)
```

**证明要点**：
1. 截断 `max(·,0)` 是对凸集 `[0,∞)` 的投影且 `τ²∈[0,∞)`，非扩张 ⇒ `|τ̂²−τ²| ≤ |Ŝ² − σ̄² − τ²|`，故可用未截断方差
2. 高斯非同分布二次型 `Q = Σ(X_g − X̄)² = XᵀPX`，`Var Q = 2 tr((PV)²) = 2[(1−2/G)Σv_g² + (Σv_g)²/G²]`；除以 `(G−1)²` 得 `V`
3. T1 + Chebyshev

**iid 一致性检查**：`v_g ≡ v` 时 `V = 2v²/(G−1)`（标准结果）。

**渐近**：`V ~ 2M₂/G` ⇒ (★) 以 `O(1/(G·gap·τ²))` 收敛，**斜率 −1**（W6-H5 曾观测 −1.071，本轮给出解释）。

**已知失效模式（必须如实报）**：`τ² → 0` 或 `gap → 0`（所有群等大 / deff→0 / deff→∞ 使 f 饱和）时界发散 → **不可识别条件**。这正是 W6-H5「小 G 时 domination 不成立」的理论对应。

### T3｜噪声尺度误设的确定性超额风险（解释 W10-M1）
若真实噪声 `σ²_g`，但算法按 `c·σ²_g`（`c = deff > 0`）计算权重 `λ̃_g = τ²/(τ²+cσ²_g)`，则
```
R_g(λ̃_g) − R*_g = τ⁴ σ²_g² (c−1)² / [ (τ²+cσ²_g)² (τ²+σ²_g) ]
```
`c=1` 时恒为 0；`c≠1` 时恒 ≥0 且随 `|c−1|` 增大。**推论**：在 W10 的合成 DGP 里噪声按 `1/n_g` 建模，M1 用 `deff≈1.944/n_g` 属**故意误设**，故平均 ΔECE 显著变差是定理预期，不是实现 bug；其尾部改善来自更强收缩，二者不可兼得。

### T4｜患者重复测量进入 Jensen gap
`σ²_g = deff/n_g` ⇒ `σ̄² = deff·mean(1/n)`，
```
gap(deff) = f(deff·s̄) − mean_g f(deff·s_g),   s_g = 1/n_g
```
当 `deff → 0`：gap → 0（所有噪声趋零，f 近线性）；当 `deff → ∞`：gap → 0（f 饱和到 τ²）。**gap 对 deff 非单调，存在有限最优尺度**。
可用严格凹下界：`gap ≥ τ⁴·Var(S)/(τ²+S_max)³`，`S = σ²_g`。
