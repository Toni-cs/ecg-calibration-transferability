## 1. 四条定理（全部推导完成）

设 `θ_g = μ + a_g`（`Var a = τ²`），无标签估计 `X_g = θ_g + ε_g`（`Var ε = σ²_g = deff/n_g`），`v_g = τ²+σ²_g`，`τ̂² = max(var(X,ddof=1) − σ̄², 0)`，`λ̂_g = τ̂²/(τ̂²+σ²_g)`。

### T1｜超额风险的精确二次分解（确定性，无概率）
```
R_g(λ̂_g) − R*_g = σ²_g²(τ̂²−τ²)² / [ (τ̂²+σ²_g)² (τ²+σ²_g) ] ≤ (τ̂²−τ²)²/τ²
```
**5,760 次检查，最大相对误差 2.05×10⁻¹²，100% 在 1e−10 内** ✅

### T2｜非渐近 domination 失败界（本轮主定理）
高斯非同分布二次型给出 `V = Var(τ̂²) = 2[(G−2)M₂ + v̄²]/(G−1)²`（`M₂ = mean v_g²`）；结合 T1 的 `Δ ≤ e²/τ²` 与 Chebyshev：
```
P( R_hetero(λ̂) > R*_hetero + δ ) ≤ min(1, V/(δ·τ²))
取 δ = gap = R_homo − R*_hetero：
P( R_hetero(λ̂) > R_homo )       ≤ min(1, V/(gap·τ²))              ... (★)
```
- **独立验证**：解析 `V` 与 200,000 次直接 MC 的比值在 G=4…128 上为 **0.995–1.004**；iid 极限精确退化为标准结果 `2v²/(G−1)` ✅
- 截断 `max(·,0)` 是对含 `τ²` 凸集的投影、非扩张，故可用未截断方差，推导严格成立
- **渐近**：`V ~ 2M₂/G` ⇒ (★) 以 `O(1/(G·gap·τ²))` 收敛

### T3｜噪声尺度误设的确定性代价
```
R_g(λ̃_g) − R*_g = τ⁴σ²_g²(c−1)² / [ (τ²+cσ²_g)² (τ²+σ²_g) ],   c = deff
```
`c=1` 恒为 0，**2,880 次检查最大相对误差 2.30×10⁻¹⁴** ✅；数值最优 `c ≈ 1.018`，即「正确设定」附近。

### T4｜患者重复测量进入 Jensen gap
`gap(deff) = f(deff·s̄) − mean f(deff·s_g)`，`s_g=1/n_g`。严格凹下界 `gap ≥ τ⁴Var(S)/(τ²+S_max)³` 在 **576/576 格成立** ✅；`deff→0`（噪声趋零）与 `deff→∞`（f 饱和）两端 gap 都趋于 0，**非单调**。

### 最关键的数字：**界是有效的，但几乎没用**

**538/576 格（93.4%）的 (★) 界等于 1（平凡）**；剩下 38 格全在 `G≥64, τ²≥0.2`。在非平凡格上，最大 `经验失败率/界 = 0.0089`——**界比真实风险宽 100 倍以上**。

> 这不是推导错，是 Chebyshev + `Δ≤e²/τ²` 这两层粗化的必然结果。它给出一条真实结论：**在 W6–W10 的合成参数区间里，「用 Chebyshev 给非渐近保证」这条路走不通**；`τ²→0`、`gap→0`（群等大 / deff 两端）时界发散，正是 W6-H5「小 G 时 domination 不成立」的理论对应。

### A3 为什么没过（归因已查清，不甩给截断）

- 冻结判据的「非平凡 + τ²≥0.2 + CV≥0.5 + deff≤2」子集**只剩 G=64、128 两个点**（27 格），log-log 回归自由度不足
- 更重要的：该网格里 `gap` 本身随 G 系统变化；**即使改用未截断解析界，同一子集斜率仍是 −0.590**，所以主因是子集选择，不是 `min(1,·)` 截断
- 对照：在**全部 G**（排除 96 个 `gap=0` 的 cv=0 格，共 480 格）上，未截断界斜率为 **−1.308**，接近理论 −1 ✅

### A5 为什么没过（同 W7-P3 的构造问题）

21/144 反例**全部是 CV=0**：群等大 ⇒ `σ²_g` 全相等 ⇒ `gap ≡ 0` 对任意 deff 都成立，于是严格不等式 `g(0)<g(1)` 按构造不可能。**排除 CV=0 后非单调性 100% 成立**；gap 下界本身 576/576 成立。判据写死了「每一格」，所以按 §6 **判 FAIL，不改判据、不删格**。
