# 预注册｜W11-B 百级验收粒度扩展（冻结）

**版本**：v1.0（终局）
**冻结时间**：2026-11-06（Asia/Shanghai）
**性质**：**验收粒度扩展，不是新实验、不是新结论**。
**冻结后执行**：三组清单各 **120 条独立断言**（理论 TH001–TH120 / preflight PF001–PF120 / verify VG001–VG120），合计 **360 条**。

---

## 0. 为什么要做，以及不做的是什么

用户要求把「理论判据 4/6、preflight 7/7、verify 12/12」这些**检查项数量**提到百级。

**本轮做**：把原来 6 / 7 / 12 个**粗粒度判据**拆成 120 / 120 / 120 个**细粒度、各自拥有独立失败条件**的断言。每条断言都必须：

1. 检查一个**与其他断言不同的对象**（不同参数格 / 不同文件 / 不同字段 / 不同分片集 / 不同轮次）
2. 有**事前写死的独立失败条件**，不是同一个 `if` 复制 120 遍
3. **真实执行**，允许 FAIL；出现 FAIL 如实报，不修到全绿
4. 不修改 W1–W11 任何原始结果、任何原始判据、任何逐种子数值

**本轮不做**：不新增实验、不新增种子、不新增方法、不改定理、不重跑确认性种子、不放宽任何原有判据。

> **诚实声明（最重要）**：**检查项变多 ≠ 更严谨，更 ≠ 离一区更近。** 一区七维里卡住的仍是 6（真实 1.15M 队列，DUA）与 7（临床+生统+第三方）。百级验收只让第三方能查得更细，不产生任何新的科学结论。W11 原始「理论 4/6、可复现包 12/12」**原样保留，不被替换**。

## 2. 断言类型与判定口径（事前冻结，防止拿证伪凑绿）

每条断言带 `kind`：

| kind | 含义 | PASS 定义 |
|---|---|---|
| `verify` | 期望条件成立 | 条件成立 |
| `falsify` | **证伪类**：期望检测到预期的退化/失败/异常 | **正确触发异常**才算 PASS；「没触发」判 FAIL |
| `meta` | 元门：确认原始记录存在且为 PASS | 原始记录存在且 PASS |

只有 TH086–TH095 共 10 条是 `falsify`；VG082–VG093、VG114–VG120 共 19 条是 `meta`；其余 331 条是 `verify`。

**`falsify` 类的意义**：它们 PASS 恰恰意味着「检测到了负面事实」（界平凡/发散、精确退化等），不是把失败包装成成功。报告必须单列这 10 条的 `observed` 数值。

## 3. 事前豁免（唯一一处，写死，不是事后放水）

`SEED_MANIFEST.json` 中 `W11 / gap_nonmonotone_grid` 是**非连续离散种子集**（144 个离散值），`n` 不等于 `end−start+1`。

**事前规则（三类别统一，冻结时写入，不是看到 FAIL 后加的）**：

| 类别 | 判据 |
|---|---|
| `continuous`（有 start/end 且 note 无特殊标记） | `start ≤ end` 且 `n == end−start+1` |
| `NON-CONTIGUOUS`（note 显式声明） | `n == 144` 且 `start == min(实际 144 值)` 且 `end == max(实际 144 值)` |
| `no-seed`（start/end 均为 null） | `n` 为 null 或 0，且 `note` 字段非空并说明原因 |

PF089–PF116 同理：有界区间与其余所有有界区间无交集；无界区间确认 `note` 声明了「无种子消耗 / 复用既有分片」。

**执行前补充说明（pre-execution，留痕）**：初版 §3 只写了 `NON-CONTIGUOUS` 一种豁免，但 `SEED_MANIFEST.json` 里还有 W1 `synthetic_grid` 与 W8 `none` 两个 `start/end = null` 的区间；「28 个区间逐条检查」必然要处理它们，故补上第三类别。原 `no-seed` 区间**不消耗任何种子**，这一事实在 W8 报告与 W9 预注册里已写明，不是新决定。

W11 原始 `a5_seed_disjoint` 已用同样的豁免逻辑，本轮不改它。
