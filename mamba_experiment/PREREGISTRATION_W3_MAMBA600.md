## 1. 架构变更（用户指定，事前固定）

| 项 | 内容 |
|---|---|
| 新骨干 | **对角 selective state-space block**：input-dependent Δ/B/C、门控因果卷积 + SSM scan（Mamba-1 / S6 的**对角状态近似**） |
| 实现 | numpy，逐种子**独立随机初始化权重**；源码 `mamba_gst.py` |
| 分类器 | 冻结的源域 ridge readout（含源域统计量标准化，部署时固定） |
| 校准 | **GST**（每群独立无标签拟合 T̂_g），沿用 T1 v0.2；**不含图正则**（W2 已否证） |
| 对照骨干 | CNN-1D（独立种子集，见 §5） |

**诚实边界（必须写进论文）**：这不是官方 Mamba CUDA kernel、不是预训练权重、不是真实 ECG 波形；是合成 12 导联 toy waveform（L=48 下采样）+ 对角 SSM 近似。真实 1.15M 波形前向仍需 PhysioNet DUA，须另按 T1 preflight 执行。**本轮结果不得外推为真实数据结论。**

### 部署协议（与真实设定一致）
- 源域**有标签** → 拟合 readout + 用 NLL 网格拟合 `τ_s`（标准 TS）+ 得到 `h_ref`
- 目标域**无标签** → 只用置信度直方图 `Ψ_g(T)=‖h_g(softmax(z_g/(τ_s T)))−h_ref‖²` 拟合 T̂_g
- 目标域标签**仅用于最终 ECE/NLL/Brier 打分**
- ORACLE = per-group 目标域 NLL 最优温度（**cheating skyline，只作上界与 F0 自检，决不作为估计器呈现**）

## 2. 600 个独立种子（主跑）

| 项 | 冻结值 |
|---|---|
| 种子范围 | **3000–3599**（600 个，与 W1/W2 的 0–29 / 1000–1029 / 2000–2029 完全不重叠） |
| 独立性 | 每种子独立采样：Mamba 权重、源域波形与标签、目标域波形与标签、G=12 群的真实温度、群规模 |
| 群温度 | `log T_g = 家族均值 ± spread(0.9) + N(0,0.08)`，3 个家族 |
| 群规模 | 长尾 lognormal，clip [15, 600] |
| T 网格 | `exp(linspace(log 0.4, log 8.0, 241))` |
| τ_s 网格 | `exp(linspace(log 0.05, log 10.0, 161))` |
| ECE | top-label 10-bin equal-width（**全程不变**） |
| Ψ 直方图 | 固定概率刻度 15-bin（rank 统计禁用） |

> 600 个种子是**事前固定的稳健性验证**，不是用来挑好看数字。全部 600 个 Δ 值逐条保存，报告 min / max / 中位 / 四分位 / 负值比例 / 最差 10 个种子。

## 3. 主终点与判定（冻结）

`ΔECE = ECE(GST) − ECE(GLOBAL)`，按群规模加权。

**通过需同时满足**：
1. `mean ΔECE ≤ −0.020`
2. ≥ **540/600**（90%）种子为负
3. **跨种子 paired bootstrap**（抽样单位 = 种子，B=10,000）95% CI 上界 < 0
   > 抽样单位从一开始就固定为种子，避免 W2 v1.0 的单种子记录级 bootstrap 错配

### F0 有效性门槛（先于一切结果，硬性）
1. **每种子** ORACLE 的 **NLL** ≤ 所有无标签估计器最优 NLL + 1e-6（ORACLE 本身按 NLL 拟合，故为严格自检）
   > ECE 是分箱估计量，与 NLL 最优温度可不重合；**不设 ECE 门槛**，但如实报告 ECE 反转种子数与最大 gap（预跑观察约 0.005 量级，属已知分箱噪声）
2. **操控有效性**：`mean(ECE_SOURCE − ECE_GLOBAL) > 0.02` 且 ≥ 90% 种子为正
   > 证明群温度失真确实造成可修复的误校准；若为 0，说明 Ψ 平坦、所有估计器撞网格边界，实验无效
3. F0 任一不满足 → **全部结果作废，修实现后重新冻结注册**

### 次要终点
NLL、Brier、`τ_s` 分布、每群 T̂_g 分布、GST vs SHRINK vs TRUE-T vs ORACLE 完整对照、小群子集 ECE。
