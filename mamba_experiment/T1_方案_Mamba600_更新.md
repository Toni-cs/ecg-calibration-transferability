## 3. 主方法：GST（不变）

```
Psi_g(T) = || h_g(softmax(z_g / (tau_s T))) - h_ref ||^2    # 无标签
T_hat_g  = argmin_T Psi_g(T)                                 # 每群独立
```

- 群由**可观测部署元数据**定义：cart_id / site / 年份 / 导联子集 / 采样率
- 源域有标签 → 拟合 readout + `τ_s`；目标域无标签 → 只拟合 T̂_g
- **不含图正则**（W2 v1.1 两批确认有害、F-B 方向翻转，已删除）
- **不含患者内配对**（W1 PARI 已否证）
- 不学 embedding→T 映射（区别 MD-TS）、不改模型（区别 ECL）、不从 3 标量恢复正确率曲线（不触碰 Transfer Gap 不可识别性）

### W3 给出的效应量（合成层，不外推）
`ΔECE(GST−GLOBAL) = −0.0248`，跨种子 CI **[−0.0269, −0.0228]**，p<0.0001；**534/600 (89.0%)** 种子为负；CNN-1D 对照 −0.0266（88/100）；F-M1/M2/M3 全部通过。

**按冻结预注册，H1 形式判定为 False**（差 6 个种子未达 90% 线），GST-on-Mamba 降级为探索性，阈值未改、无 v0.4。该判定保留在论文与附录中。

## 4. 新增待注册假设：gated-GST（**未确认，不得宣称已解决**）

W3 暴露 **66/600 (11%)** 种子 GST 反而有害（最差 +0.0332 ECE）。这直接说明无条件分群校准不能进部署，需要三态门控 `(KEEP-GLOBAL / GST / ABSTAIN)`。

**探索性分层结果（明确不可作确认性证据）**：按操控强度分层，low −0.0325 / mid −0.0263 / high −0.0141，`corr = +0.267` —— **与直觉相反，简单"失真强度 gate"不成立**。

**下一轮 T1 需新预注册检验的候选门控统计量**（全部无标签、事前冻结阈值）：
- Ψ_g 曲线极小深度 / 曲率（平坦 = 不可识别 → ABSTAIN）
- 群内置信度直方图方差与有效样本量
- 每群 T̂_g 的 bootstrap 稳定性
- 与源域 `h_ref` 的最小可达距离

**硬约束**：门控阈值必须在任何真实数据前向之前注册；不得用 W3 的 600 种子事后挑阈值；若门控未通过，按失败条款如实发表。

## 6. 终点与外验（T1，不变）

- 主终点：`ΔECE = ECE(GST) − ECE(GLOBAL)`，阈值 **−0.020**，跨外验折/种子 paired bootstrap（单位 = 折），患者级 block CI
- 三类非 in-sample 外验：**leave-one-site / leave-one-cart / leave-one-year**
- 对照：SOURCE / GLOBAL / GST / SHRINK / BCTS / BBSE / MD-TS / ECL / Wang et al. / oracle
- 分层：慢性 vs 阵发（阵发层必须单独报，即使不利）、标签本体映射敏感性、导联下标错位对照
- 统计：patient-block BCa B=10,000；I² 高时禁用固定效应区间
