## 1. 命题 2（本轮理论贡献）

设 `θ_g ~ (μ, τ²)`，无标签估计 `X_g = θ_g + ε_g`，**异方差** `Var(ε_g) = σ²_g = 1/n_g`。取 pooled 均值 `m`：

```
逐群 BLUP:      λ_g* = τ²/(τ²+σ²_g),   R_g = f(σ²_g) = τ²σ²_g/(τ²+σ²_g)
同方差 BLUP:    λ̄  = τ²/(τ²+σ̄²),     R_homo = f(σ̄²),  σ̄² = mean σ²_g
因 f''(x) = −2τ⁴/(τ²+x)³ < 0（严格凹），Jensen 给出：
            R_hetero = mean f(σ²_g) ≤ f(mean σ²_g) = R_homo
等号当且仅当所有群等大。
```

**推论**：小群 `σ²_g` 大 ⇒ `λ_g*` 小 ⇒ 自动更强收缩回 GLOBAL；大群保留分群收益。这正是 W7-P5 指向的机制，且**零超参、无阈值、无需探索集选任何参数**（W8 教训的直接应用）。

**H6 数值验证**：144 个网格单元（G∈{4…128} × CV(n_g)∈{0…2.0} × τ²∈{0.05…1.0}）中 **`R_hetero ≤ R_homo` 成立 144/144 = 100%**；群规模不均衡度与 Jensen 差额的 Pearson **r = 0.9626**；CV=0 时差额恰为 0，CV=2.0 时 0.01951。✅

## 2. 方法 HB-GST（零超参）

```
τ̂² = max(Var(log T̂_g) − mean(1/n_g), 0)
Gate 1（命题 1）: τ̂² ≤ mean(1/n_g) ⇒ λ_g = 0 ∀g（回退 GLOBAL）
否则:             λ_g = τ̂²/(τ̂² + 1/n_g)
T̂_g = exp(λ_g·log T̂_g + (1−λ_g)·log T_global)
```

八个估计器全报：`SOURCE / GLOBAL / GST / SR-GST / GS-GST / CERT-GATE / HB / LB(探索性对照)`。

## 4. 三项未过，逐项如实解释

### H1｜事后「阈值伪影」假设被自己的数据否证

我原本怀疑：连续收缩让很多种子从「明显优于 GLOBAL」变成「勉强优于」，跨过 0.002 容差后被误记为 harm。于是做了**明确标注为 post-hoc、不进任何 H 判定**的诊断（`posthoc_diagnostics.py`）：

| 连续量 | CERT-GATE | HB-GST |
|---|---|---|
| mean 连续部署损失 | **0.00095** | 0.00098 |
| p99 ΔECE | **0.00616** | 0.00668 |
| **CVaR 0.1%（自身最差 10 个）** | **0.01598** | 0.01731 |
| max ΔECE | **0.02514** | 0.02668 |
| 新危害事件落在容差 ±0.003 内的比例 | — | **0.0%** |

**假设不成立**：HB 的连续损失、p99、CVaR、max 全都略高，新危害事件**没有**聚集在阈值边界。所以 H1 失败不是度量伪影，是真实效应：

> HB 改善了 **CERT 的**最差 10 个场景（H3 ✅），却产生了**自己的、更差的**新尾部（CVaR 0.01731 vs 0.01598）。**修了旧尾部，造了新尾部。**

这与 W7-P5「残余危害集中在证书判可分群的场景」同构：任何更强的收缩都会把风险搬运到别处。按 §6，**H1 判 FAIL，不改判据、不换估计器、不补种子**。

### H4｜分层只 9/20，但机制是清楚的

低异质箱（spread 0.086）HB 0.0076 < CERT 0.0095 ✅；中异质箱（0.449）HB 0.0611 > CERT 0.0489 ❌。**异方差 BLUP 在中等异质、长尾群上收缩不足**，正是命题 2 的渐近条件（G→∞、τ² 已知）与有限样本估计误差之间的缝。W6-H5 已见过同类现象（小 G 时 λ̂ 噪声破坏 domination）。

### F4｜判据本身写错了（同 W7-P3、W8）

`spread=0` 只消除 `θ_g` 的异质，**不消除** `σ²_g = 1/n_g` 的异方差；而 HB 与 CERT 的全部差别正来自异方差。所以「HB 应≈CERT」这个预期在机制上就不成立，实测 0.00918 是**预期结果**。按 §6 **删除 F4 的因果解释**，判据设定不当如实记录，不改阈值。
