## 1. 命题 2（本轮理论贡献，可证明）

设 G 个部署群，`θ_g = log T_g* ~ (μ, τ²)`，无标签估计 `X_g = θ_g + ε_g`，**异方差** `Var(ε_g) = σ²_g = 1/n_g`（W3/W5 的 Ψ 估计噪声 ∝ 1/n_g，长尾群规模使其天然异方差）。取 pooled 均值 `m`。

**(a) 逐群 BLUP**：平方损失下 `δ_g = m + λ_g(X_g − m)` 的最优权重与风险为

```
λ_g* = τ²/(τ² + σ²_g)
R_g(λ_g*) = τ²σ²_g/(τ²+σ²_g) =: f(σ²_g)
```

**(b) 同方差 BLUP**（W6/W7 的 GS-GST）：令 `σ̄² = mean_g σ²_g`，`λ̄ = τ²/(τ²+σ̄²)`，总风险

```
R_homo = mean_g [ λ̄²σ²_g + (1−λ̄)²τ² ] = λ̄²σ̄² + (1−λ̄)²τ² = f(σ̄²)
```

**(c) 严格改进**：`f(x) = τ²x/(τ²+x)` 在 x>0 上**严格凹**（`f'' = −2τ⁴/(τ²+x)³ < 0`），由 Jensen：

```
R_hetero = mean_g f(σ²_g)  ≤  f(mean_g σ²_g) = R_homo
```

**等号当且仅当所有 σ²_g 相等（所有群等大）**。群规模越不均衡（长尾越重），优势越大。

**推论（直接对应 W7 P5）**：小群 `n_g` 小 ⇒ `σ²_g` 大 ⇒ `λ_g*` 小 ⇒ **自动更强地收缩回 GLOBAL**；大群保留分群收益。所以平均校准增益不必牺牲，残余危害却下降——这正是硬门做不到的。

> 不声称首次 BLUP / 首次经验 Bayes / 首次异方差收缩。边界 = **首次在 ECG 无标签 post-hoc 温度校准 + 层级长尾部署群下，把命题 1 推广为命题 2，并用它解释和修复 0.1% 尾部失效**。

## 2. 方法：HB-GST（零超参）

```
tau2_hat = max( Var(log T_g_indep) − mean(1/n_g), 0 )
sigma2_g = 1/n_g
Gate 1（命题 1）: 若 tau2_hat ≤ mean(1/n_g)  ⇒  λ_g = 0 ∀g  （回退 GLOBAL）
否则:            λ_g = tau2_hat / (tau2_hat + sigma2_g)
T̂_g = exp( λ_g·log T_g_indep + (1−λ_g)·log T_global )
```

全部量来自**无标签目标域置信度直方图**与群规模元数据；**零可调参数、零阈值、无需探索集选任何东西**（这是 W9 相对 W8 最关键的防 HARKing 设计）。

**探索性对照**（不作主判据、不进任何 H 判定）：全局 jackknife 下界 `λ_LB = clip(λ − 1.96·SE_jack, 0, 1)` 的单参数收缩 `LB`，与 HB 并列报告。W8 debug 已见 LB 反而略差，本轮只作描述。

八个估计器全报：`SOURCE / GLOBAL / GST / SR-GST / GS-GST / CERT-GATE / HB / LB`。

## 4. 主判据（冻结；不预设效应量，避免挑数字）

| ID | 判据 |
|---|---|
| **F0** | 操控有效性 `mean(ECE_SOURCE−ECE_GLOBAL)>0.02` 且 ≥90% 种子为正；GST≤GLOBAL 方向一致性 ≥60% |
| **H1（主）** | `harm(HB) < harm(CERT)` **且** paired bootstrap（单位=种子，B=10,000）`harm(CERT)−harm(HB)` 的 **CI 下界 > 0**；相对降幅仅作**描述性**报告 |
| **H2（严格非劣）** | `mean ΔECE(HB) ≤ mean ΔECE(CERT) + 0.002`（平均校准增益不得丢失） |
| **H3（尾部）** | 在 **CERT 的尾部 0.1%（10 个最大 ΔECE_CERT）种子**上，`mean ΔECE(HB) ≤ mean ΔECE(CERT)`；且这 10 个种子里 `harm(HB) ≤ harm(CERT)` 的个数 ≥8 |
| **H4（分层一致性）** | spread 20 等宽箱中，`harm(HB) ≤ harm(CERT)` 的箱数 ≥15；且 λ_g 的群间标准差 > 0（确认异方差确实生效） |
| **H5（架构）** | 1,000 个 CNN 种子的 `mean ΔECE(HB)` 与 9,000 Mamba **同号且 ≤ −0.002** |
| **H6（命题 2 数值验证）** | 独立数值网格上 `R_hetero ≤ R_homo` 成立比例 ≥0.99；且群规模不均衡度（CV of n_g）与 `R_homo−R_hetero` 的 Pearson r ≥0.8 |

`harm` 沿用 W7：`ECE_k > ECE_GLOBAL + 0.002`（事前非劣容差）。

> 判据用「CI 下界 > 0 / 严格非劣 / 不恶化」这类**通用统计条件**，不设「降 50%」这类看过 debug 才敢写的数字。W8 的教训：预设效应量会诱导挑阈值。
