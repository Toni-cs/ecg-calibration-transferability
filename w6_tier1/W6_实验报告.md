## 1. 命题 1（本轮理论贡献）

设 G 个部署群，真温度 `θ_g = log T_g* = μ + u_g`，`u_g ~ (0, τ²)`；无标签估计 `X_g = θ_g + ε_g`，`Var(ε_g) = σ²`（W3/W5 的 Ψ 估计噪声 ≈ 1/n_g）。取 `m = mean(X)`，收缩估计 `δ_g(λ) = m + λ(X_g − m)`。当 G→∞：

```
R(λ) = (1−λ)² τ² + λ² σ²
λ*   = τ² / (τ² + σ²)
R(λ*) = τ²σ² / (τ²+σ²) ≤ min(τ², σ²)
R(1) = σ² （GST）    R(0) = τ² （GLOBAL）
```

**推论**：
1. **GST 优于 GLOBAL 当且仅当 `σ² < τ²`** —— 这正是 W3 已冻结 §S1 敏感性网格「spread↓ ⇒ 增益↓」的闭式解释
2. 收缩风险永不超过两者中较优者
3. **部署证书**：`τ̂² ≤ σ̂² ⇒ 回退 GLOBAL（不做分群）`；否则用 GS-GST。`τ̂² = max(Var(X) − mean(1/n_g), 0)`，`σ̂² = mean(1/n_g)`，**完全无标签、零超参**

**CERT-GATE** = 证书的直接部署化。这是 W5 之后真正该有的增量：**不是又一个估计器，而是一张带理论依据的「何时不该分群校准」证书**。

> 不声称首次收缩、首次分域温度、首次校准门控。边界 = 首次在 ECG 层级漂移 + 患者级统计 + 非 in-sample 外验下，把随机效应风险分解转成可证明的无标签部署证书。

## 3. 主结果（11/14 通过）

### 通过的 11 项

| 检查 | 结果 |
|---|---|
| **F0 有效性** | 操控有效性 0.0682 / 97.2% 为正；AUROC 0.627（18/600 种子因极小单类群无定义，nan-aware 处理并如实记录）；600/600 ORACLE 的 NLL 最优 |
| **H1 主终点** | 危害率 **GST 0.0967 → CERT-GATE 0.0133**，相对下降 **86.2%**，paired CI **[0.0617, 0.1067]** 下界 >0 |
| **H2 证书准确率** | A 层 **100%** 判 GST；B 层 **94%** 判 GLOBAL；λ_A 0.833 / λ_B 0.202 |
| **H3 完整指标链** | **9/9 指标不劣**；主终点 ΔECE_canonical **−0.00333**，CI **[−0.00375, −0.00293]** 上界 <0 |
| F-M1 合并群 | ΔU_CERT = **0.000000**（精确退化 GLOBAL） |
| F-M2 置换 group_id | 优势消失，5.3×10⁻⁵ |
| F-M3 群同质 | GST 增益 −0.00146（≈0） |
| **F-M4 λ≡1 / λ≡0** | GS-GST 逐位等于 GST / GLOBAL，max 差 **0.0 / 2.8×10⁻¹⁷** |
| F-M5 随机证书 | 优势大幅消失 |
| **CNN-1D 对照** | −0.00308，72/100 正向，与 Mamba −0.00333 同号 |

**9 指标全部改善**（Δ = CERT-GATE − GLOBAL，负=改善）：
`ECE_top −0.0142`、`ECE_classwise −0.0057`、`ECE_canonical −0.0033`、`Brier −0.0087`、`NLL −0.0349`、`cal_intercept −0.0276`、`cal_slope −0.0334`、`AUROC −0.0004`、`DCA −0.0002`。

**分层看机制更清楚**：

| 层 | GST 危害率 | CERT-GATE 危害率 | 证书判 GLOBAL |
|---|---|---|---|
| A 高异质 | 0.030 | 0.0233 | 0% |
| **B 低异质** | **0.1633** | **0.0033** | **94%** |

B 层正是「不该分群」的场景：无条件 GST 在 16.3% 部署里有害，证书 94% 正确回退，危害压到 0.33%。这就是命题 1 的价值。
