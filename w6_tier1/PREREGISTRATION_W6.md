## 1. 本轮主方法：CERT-GATE（显式部署证书）

**命题 1（风险分解，本轮理论贡献）**

设 G 个部署群，真温度 `θ_g = log T_g* = μ + u_g`，`u_g ~ (0, τ²)`；无标签估计 `X_g = θ_g + ε_g`，`Var(ε_g) = σ²`（W3/W5 的 Ψ 估计噪声 ≈ 1/n_g）。取 pooled 均值 `m = mean(X)`，收缩估计 `δ_g(λ) = m + λ(X_g − m)`。当 G→∞：

```
R(λ) = E[(δ_g − θ_g)²] = (1−λ)² τ² + λ² σ²
λ*   = τ² / (τ² + σ²)
R(λ*)= τ²σ² / (τ²+σ²)  ≤  min(τ², σ²)
R(1) = σ²  （GST，不收缩）
R(0) = τ²  （GLOBAL，全收缩）
```

**推论**：
1. **GST 优于 GLOBAL 当且仅当 σ² < τ²**（估计噪声 < 真实异质）——这正是 W3 `PREREGISTRATION_W3_MAMBA600.md §S1` 已冻结敏感性网格「spread↓ ⇒ 增益↓」的闭式解释。
2. **收缩风险永不超过两者中较优者**，且严格小于两者中较差者。
3. **部署证书**：`τ̂² ≤ σ̂² ⇒ 应当回退 GLOBAL（不做分群）`；`τ̂² > σ̂² ⇒ 用 GS-GST`。其中 `τ̂² = max(Var(X) − mean(1/n_g), 0)`，`σ̂² = mean(1/n_g)`，**完全无标签、零超参**。

**CERT-GATE** = 上述证书的直接部署化：
```
if τ̂² ≤ σ̂²:  T̂_g = T_global      （全群回退）
else:        T̂_g = GS-GST 的 λ 收缩
```
这是 W5 之后真正该有的增量：**不只是一个估计器，而是一张带理论依据的「何时不该分群校准」证书**。

> **不声称**：首次收缩（CTG / James–Stein 已有）、首次分域温度（MD-TS, NeurIPS 2022）、首次校准门控（BUDDY / HG-CRC / S-MMCE）。novelty 精确边界 = **首次在 ECG 层级漂移、患者级统计、非 in-sample 外验下，把随机效应风险分解转成可证明的无标签部署证书**。

## 2. 层级 DGP（冻结）

```
site(3) × cart(4) × year(3) = 36 部署群
log T_g = μ + a_site + b_cart(site) + c_year + N(0, 0.06²)
μ = 0.55                      # 目标域系统性过置信（源域 T=1 已校准）
a ~ N(0, (0.50·s)²), b ~ N(0,(0.35·s)²), c ~ N(0,(0.20·s)²)
群规模长尾 LogNormal(0, 0.85²)，总 n = 1800
每患者 1–5 条重复记录，均值 ≈ 2.9（对应 1,145,814 / ≈395,122）
患者内随机效应 d_p ~ N(0, 0.06²) 加到 logits
```

**两层主设定（事前声明，不是事后挑的）**：
- **A 层 `s=1.0`**：高异质，应当分群（证书应判 GST）
- **B 层 `s=0.20`**：低异质，分群只引入噪声（证书应判 GLOBAL）

B 层依据：W3 §S1 敏感性网格 + W4 F4（危害来自小 split 过拟合而非漂移）+ W5 λ≈0.18 的实测。

## 4. 指标与主终点（冻结）

**9 指标全链**（每估计器每群算，按群规模加权）：
`ECE_top`, `ECE_classwise_macro`, `ECE_canonical`, `Brier`, `NLL`, `cal_intercept`, `cal_slope`, `AUROC`, `DCA_net_benefit(t=0.1/0.2/0.3 平均)`

定义要点：
- `ECE_classwise_macro`：每类独立按 `p_k` 分箱的二值 ECE 宏平均
- `ECE_canonical`：按 **top-label 置信度**分箱，箱内算**整个概率向量**与 one-hot 的平均绝对偏差（与 classwise 定义不同）
- `cal_slope/intercept`：**ridge 正则 + 步长截断**的 IRLS（未正则化 Newton 在饱和置信度下发散，见 E1）
- `DCA_net_benefit`：多阈值净获益

**主终点 = `ECE_canonical`**。不把不同量纲指标裸加成单一 utility（ECE≈0.1、NLL≈1.4、AUROC≈0.55、slope≈1）。其余 8 指标各自报 mean Δ 与 CI。

**harm 判据**（事前）：`U_k > U_GLOBAL + 0.002`。0.002 约为主效应（≈0.006）的 1/3，是**非劣性容差**，避免分箱估计量的微小抖动被记成危害。

### 假设

| ID | 判据 |
|---|---|
| **H1（主）** | 合并 600 种子：`harm(CERT-GATE) ≤ 0.025` **且**相对 `harm(GST)` 下降 ≥50% **且** paired bootstrap（单位=种子，B=10,000）`harm(GST)−harm(CERT-GATE)` 的 CI 下界 > 0 |
| **H2** | 证书准确率：A 层 ≥85% 判 GST；B 层 ≥85% 判 GLOBAL |
| **H3** | 完整链 9 指标中 CERT-GATE 相对 GLOBAL **不劣**的指标数 ≥7；且 `mean ΔECE_canonical(CERT-GATE − GLOBAL)` 的 CI 上界 < 0 |
| **H4** | 三类 LOCO（site 3 折 / cart 12 折 / year 3 折）中，CERT-GATE 不劣于 GST 的折数比例 ≥2/3 |
| **H5（命题 1）** | `P(R(λ̂) ≤ min(R(1),R(0))) ≥ 0.95`；`mse(λ̂)` 对 G 的 log-log 斜率 ≤ −0.7（理论 −1） |
| **H6（患者级）** | `n_eff/n ∈ [0.40, 0.65]`；patient-block ΔECE CI 宽度 ≥ record-level ×1.05 |

### F0 有效性门槛（先于一切结果）
1. 操控有效性 `mean(ECE_top_SOURCE − ECE_top_GLOBAL) > 0.02` 且 ≥90% 种子为正
2. `mean AUROC ≥ 0.55`
3. ORACLE 的 NLL ≤ 所有估计器最小 NLL + 1e-6（ORACLE 按 NLL 拟合）
4. 任一不满足 → **全部作废，修实现后重新冻结**

## 5. 统计口径

- **所有主判据抽样单位 = 种子**，跨种子 paired bootstrap B=10,000（W2 v1.0 单位错配的教训）
- A / B 两分层**分别报告**，即使某层不利
- 三类 LOCO 是**群级非 in-sample 外验**：λ 与 pooled T 只用训练折拟合，留出折完全不参与
- 真实 1.15M 阶段必须改用 **patient-block / 中心簇 bootstrap**；本轮每记录视作 DGP 抽样单元，明确标注差异

## 7. 附录 E1｜实现勘误（发生在任何确认性种子之前）

**时间戳**：2026-11-06，**早于** 10000–10809 任一确认性种子首次执行。
仅用 **debug 种子 9500–9899**（不属于任何确认性集合，结果不进入报告）验证实现有效性。

| # | 缺陷 | 修正 |
|---|---|---|
| E1-a | 未正则化 IRLS 在饱和置信度下发散，`cal_slope` 达 −2.6×10⁵，复合 U 被污染到 10⁶ 量级 | ridge=1.0 + Newton 步长 clip ±1；**并删除跨量纲裸加 utility，主终点改为 `ECE_canonical`**，其余 8 指标单独报告 |
| E1-b | `ECE_classwise_macro` 与 `ECE_canonical` 实现恒等（同为每类按 p_k 分箱） | canonical 改为按 **top-label 置信度**分箱 + 全概率向量偏差，二者定义真正不同 |
| E1-c | 零均值 log T 时 SOURCE 偶然接近最优，F0 操控有效性为负 | 引入系统性过置信 `μ=0.55`（真实跨中心部署常见），F0 恢复 0.067 / 12/12 为正 |
| E1-d | 单群 bootstrap 只在第 0 群上做，宽度比失真 | 改为**全目标域 + 全局患者分块**，统计量改为配对 ΔECE |
| E1-e | 无容差的二值 harm 把分箱抖动全记成危害 | 事前引入非劣容差 `HARM_MARGIN = 0.002`（≈主效应的 1/3） |
| E1-f | `fit_global` 返回长度 G 数组，LOCO 中与留出折广播冲突 | 取训练折标量 pooled 温度 |

**方法形式选择依据**：W3 已冻结 §S1 网格 + W5 实测 λ（A≈0.87 / B≈0.18）+ 命题 1 闭式推论，均为冻结前已有证据。

**不变项**：CERT-GATE 形式、600 主种子及 A/B 层、H1–H6 全部阈值、F0、五条证伪、CNN 对照、失败条款 —— 与正文逐字一致。本勘误只修**实现有效性**，不改判定规则。
