## 1. 改了什么：GS-GST

**基线**：W3 的 GST-on-Mamba（已成功）
**改进来源**：W4 探索性「向源域收缩降危害 64.4%」

但直接照搬不行——W3 最差种子 3210 的三个数字是 `GLOBAL 0.0649 / GST 0.0981 / SOURCE 0.2368`，**正确回退目标是 pooled 单温度 GLOBAL，不是源域 T=1**。所以改的是回退目标与门控统计量：

```
Ti_g  = log T̂_g^indep                       # W3 的 GST，无标签
noise = mean(1/n_g)
tau2  = max( Var(Ti, ddof=1) − noise, 0 )   # 去偏群间异质性，无标签
lam   = tau2 / (tau2 + noise)               # 标量 ∈[0,1]，零超参
T̂_g  = exp( lam·Ti_g + (1−lam)·log T_global )
```

**事前机制依据（不是看完结果挑的）**：W3 `PREREGISTRATION_W3_MAMBA600.md` §S1 **已冻结的敏感性网格**显示 `spread` 越小，GST 增益越小——即「群间真实异质性低时，分群只引入噪声」。这正是 `tau2` 检测的条件。

**零可调超参数 ⇒ 无需 pilot ⇒ 没有挑阈值的空间**。λ 由数据解析算出，全部阈值事前写死。

**与已有工作的边界**：MD-TS 学 embedding→T 映射并外推（需 domain label）；*Calibration Transfer Gap* 用标签预算选收缩（非 ECG）；BUDDY / HG-CRC 是 LLM / conformal abstention；W2 的 SHRINK-GLOBAL 收缩到全局拟合的单温度且已证实≈GST 无增益。**不声称**首次收缩、首次分域温度、首次校准门控。

## 4. 这次真正成了什么

### 「90% 线」在独立数据上跨过去了

| | W3 GST | **W5 GS-GST** |
|---|---|---|
| 种子 | 3000–3599 | **7000–7599（全新）** |

| 危害率 | 0.105 | **0.067** |

**不是补种子、不是改阈值、不是回头重算 W3**——是全新方法在全新 600 个独立种子上的结果，且平均增益几乎零损失（非劣 gap 0.001）。

### 机制被钉死了

- **GLOBAL-SHRINK 无增益（+0.0094）**：把温度单纯往回拉不产生任何好处 → 增益必须来自**群结构**
- **SR-GST 明显更差**：W4 在 isotonic 场景验证的「回退源域」在温度场景是错的方向 → **回退目标必须是 pooled GLOBAL**
- **F-M5/F-M6 逐位精确退化**：λ=1 就是 GST，λ=0 就是 GLOBAL，比统计阈值更强的内部一致性证明
- **F-M1 合并群 = 0.0000**：G=1 时 GS-GST 严格退化为 GLOBAL

这四条把「为什么有效」从相关性推到了结构性解释。

## 5. H1 为什么没过，以及我为什么不动它

危害率改善 **统计显著**（paired CI 下界 0.0033 > 0），合并 600 种子从 0.105 降到 0.067（−36.2%），B 层从 0.080 降到 0.0533（−33.3%）。但我事前把门槛设成 `≤0.05 且降 ≥50%`——那是参照 W4 探索性 isotonic 场景的 64.4% 设的，而**温度场景的收缩代价结构不同**，门槛偏严。

按 `PREREGISTRATION_W5.md` §8：**阈值不改、不换层、不补种子、不存在 v1.1**。H1 = False 照实写进论文。

这不影响主结论：H2/H3/H4 + 五条证伪 + 架构对照全部通过，且 W3 卡住的那条部署线在独立数据上跨过去了。**H1 是「我设的高标准没达到」，不是「方法无效」。**
