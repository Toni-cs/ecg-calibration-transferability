## 1. 主方法 GS-GST（零超参、全解析、无标签）

```
Ti_g  = log T̂_g^indep                         # W3 的 GST，无标签
Tglob = log( argmin_T Σ_g n_g Ψ_g(T) )         # W3 的 GLOBAL
noise = mean(1/n_g)
tau2  = max( Var(Ti, ddof=1) − noise, 0 )      # 去偏的群间异质性，无标签
lam   = tau2 / (tau2 + noise)                  # 标量 ∈ [0,1]，零超参
T̂_g  = exp( lam·Ti_g + (1−lam)·Tglob )        # 收缩回稳健的 pooled 温度
```

**事前机制依据（不是看结果挑的）**：
- W3 **S1 是已冻结预注册中的敏感性网格**：`spread` 越小，GST 增益越小。即「群间真实异质性低时，分群只引入噪声」——这正是 `tau2` 检测的条件。
- W3 最差种子 3210：`GLOBAL 0.0649 / GST 0.0981 / SOURCE 0.2368`。**正确回退目标是 GLOBAL，不是源域 T=1**。
- 因此 W4 探索性的「向源域收缩」不能照搬到温度场景；W5 把回退目标改为 pooled 温度，并把 W4 的收缩思想保留为机制。

**与已有工作边界**：MD-TS 学 embedding→T 映射并外推（需 domain label）；CTG 用标签预算选收缩（非 ECG）；BUDDY/HG-CRC 是 LLM / conformal abstention；W2 SHRINK-GLOBAL 收缩到**全局拟合的单温度**且已证实≈GST 无增益。GS-GST 是**首次把去偏异质性作为零超参门控、收缩回 pooled 温度、以部署危害率为主终点**的 ECG 无标签分群校准。**不声称**首次收缩、首次分域温度、首次校准门控。

## 2. 八个估计器（全部报，不得只挑好的）

| 名称 | 定义 | 角色 |
|---|---|---|
| SOURCE | T≡1 | 下界参照 |
| GLOBAL | pooled 单温度（= 原项目 TS / W1 pooled / W3 默认部署） | **主要对照** |
| GLOBAL-SHRINK | 对 GLOBAL 施加同样收缩 | **机制对照**：若它无增益，证明增益来自群结构而非"把温度往回拉" |
| GST | 每群独立 T̂_g（W3 已成功） | **已成功基线** |
| SHRINK-GLOBAL | W2 的 EB 收缩到全局均值 | 历史对照 |
| SR-GST | James–Stein 收缩回 **SOURCE** | **回退目标对照**：W4 方向，预期在温度场景不适用 |
| CW-GST | 按 Ψ 曲线深度逐群加权回退 GLOBAL | 逐群机制对照 |
| **GS-GST** | 见 §1 | **本轮主方法** |
| ORACLE | per-group 目标域 NLL 最优 | 上界 / F0，**绝不作为估计器呈现** |

## 4. 主终点与判定（冻结）

**harm（危害）定义**：`ECE(estimator) > ECE(GLOBAL)`，按种子计 0/1。与 W3 的「ΔECE>0 种子」口径完全一致，可直接比较 W3 的 11%。

### H1（**主终点**）｜高风险层危害率
在 **Stratum B（300 种子）**：
- `harm(GS-GST) ≤ 0.05`
- **且**相对 `harm(GST)` 下降 ≥ 50%
- **且** paired bootstrap（单位=种子，B=10,000）`harm(GST) − harm(GS-GST)` 的 95% CI 下界 > 0

> 理由：W3 已解决"平均效应存在吗"，W5 只解决"能不能安全部署"。主终点是部署安全性，不是再证明一次平均增益。

### H2（非劣，合并 600 种子）｜平均增益不牺牲
- `mean ΔECE(GS-GST − GLOBAL) ≤ −0.020` **且**跨种子 bootstrap CI 上界 < 0
- **且**非劣：`mean[ΔECE(GS-GST) − ΔECE(GST)] ≤ 0.010`

> 0.010 是**事前**按 W3 效应量 −0.0248 的约 40% 设定的收缩代价上界，依据偏差–方差折中。**这是新方法的新判据，不是修改 W3 的 −0.020 / 90% 判据。**

### H3（尾部风险，合并 600 种子）
- 95% 分位 `ΔECE` 相对 GST 改善 ≥ 0.002（即 `p95(GS-GST) ≤ p95(GST) − 0.002`）
- 最差种子（max ΔECE）相对 GST 改善 ≥ 0.002

### H4（机制，合并 600 种子）
- `GLOBAL-SHRINK` 的 `mean ΔECE ≥ −0.005`（**应无增益**，证明增益来自群结构）
- `mean ECE(SR-GST) > mean ECE(GS-GST)`（证明回退目标必须是 GLOBAL 而非 SOURCE）

### F0 有效性门槛（先于一切结果，硬性）
1. 每种子 ORACLE 的 **NLL** ≤ 所有估计器最优 NLL + 1e-6（ORACLE 按 NLL 拟合，严格自检）
2. 操控有效性 `mean(ECE_SOURCE − ECE_GLOBAL) > 0.02` 且 ≥90% 种子为正
3. 复合判别力 `mean AUROC ≥ 0.55`（沿用 W4 E1 口径）
4. 任一不满足 → **全部结果作废，修实现后重新冻结注册**

> ECE 是分箱估计量，与 NLL 最优温度可不重合；**不设 ECE 门槛**，但如实报告 ORACLE 的 ECE 反转种子数与最大 gap。

## 5. 证伪检验（7600–7659，事前固定）

| ID | 操作 | 预期 |
|---|---|---|
| F-M1 | 合并所有群为 G=1 | GS-GST ≡ GLOBAL，`|mean ΔECE| < 0.005` |

## 7. 附录 E1｜实现勘误（发生在任何确认性种子之前）

**时间戳**：2026-11-06，**早于** 7000–7799 任何种子的首次执行。
仅用 **debug 种子 9000–9023**（24 个，不属于任何确认性集合，结果不进入报告）验证实现有效性与解析形式。

| # | 发现 | 处置 |
|---|---|---|
| E1-a | 最初把 W4 的「向源域收缩」直接接成 SR-GST，debug 显示 λ≈0.85 且**harm 反而升到 0.167**（W3 最差种子里 SOURCE 0.2368 远差于 GLOBAL 0.0649） | 回退目标改为 **GLOBAL**；SR-GST **保留为对照估计器**，并据此形成 H4 的第二条机制判据 |
| E1-b | 逐群 Ψ 深度加权（CW-GST）w≈0.60，把所有群都拉向 GLOBAL 一半，稀释增益 | 保留为对照；主方法改用**种子级**去偏异质性 λ（GS-GST） |
| E1-c | F-M5/F-M6 精确退化在 debug 上验证通过 | 正式纳入 §5 |
| E1-d | `GLOBAL-SHRINK` 在 debug 上 harm 0.79–0.83、ΔECE 为正 | 正式纳入 H4 作为机制对照 |

**方法形式选择依据**：W3 最差种子的三个数值（GLOBAL 0.0649 / GST 0.0981 / SOURCE 0.2368）+ W3 **已预注册的 S1 敏感性网格**（spread↓ ⇒ 增益↓）。二者都是**冻结前已存在**的证据，不是看确认集结果。

**不变项**：GS-GST 公式（零超参）、8 个估计器、600 主种子及 A/B 分层、H1–H4 全部阈值、F0、五条证伪、CNN 对照、失败条款 —— 与 v1.0 正文逐字一致。本勘误只确定**方法解析形式**，不改判定规则。
