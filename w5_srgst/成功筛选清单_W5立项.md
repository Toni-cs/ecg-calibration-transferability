## 4. W5：接在成功结果上的一步

**基线**：W3 的 GST-on-Mamba（已成功）
**改进来源**：W4 探索性的收缩发现（已验证 −64.4%）
**新方法 SR-GST**（Shrinkage-to-Source Group Temperature）：

```
T̂_g^indep = argmin_T Ψ_g(T)                       # W3 的 GST，无标签
τ²  = max( Var(log T̂^indep) − mean(1/n_g), 0 )    # 去偏的群间异质性，无标签
λ_g = τ² / (τ² + 1/n_g)                            # James–Stein 型，零超参
T̂_g = exp( λ_g · log T̂_g^indep )                  # 收缩回已校准源域 T=1
```

**与已有工作的边界**：
- MD-TS：学 embedding→T 映射，需 domain label，未见域外推 → SR-GST 不学映射、不需标签
- W2 的 SHRINK-GLOBAL：shrink 到**全局拟合的单温度**（本身被污染）→ SR-GST shrink 到 **T=1（已校准源域）**，这是 W4 探索性验证有效的方向
- CTG 的 shrinkage：非 ECG、用标签预算选收缩 → SR-GST 完全无标签、零超参、解析式
- BUDDY / HG-CRC：LLM / conformal abstention → SR-GST 是 ECG 温度估计

**novelty 精确声明**：首次把 James–Stein 型**向已校准源域的收缩**接在 ECG 无标签分群温度上，以**部署危害率**为主终点，零超参、全解析、冻结 SSM logits。**不声称**首次收缩、首次分域温度、首次校准门控。

**为什么这次有理由预期成功（事前论证，不是看结果挑的）**：
1. W3 已证明 89% 场景 GST 优于 GLOBAL；JS 收缩对**大群 λ≈1**（长尾里大群主导加权 ECE），所以平均增益基本保留
2. W3 的 11% 有害场景集中在**小群 / Ψ 曲线平坦**（估计不稳），JS 收缩恰好对这些群 λ→0，回退到源域，消灭危害
3. W4 探索性独立验证收缩把危害率降 64%，且整体 Brier 几乎不变
4. 这是明确的偏差–方差折中，不是数据驱动的调参

## 5. 判定口径（W5 预注册将冻结，此处先声明原则）
